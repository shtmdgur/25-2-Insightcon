## 데이터 수집 전략

### 데이터 수집의 목적

온톨로지와 지식 그래프를 구축하기 위해서는 다음 두 가지 유형의 데이터가 필요합니다:

#### 1. 정적 데이터 (Static Data) - Attribute Graph 구축용

**목적**: 상대적으로 안정적인 기본 정보 저장

**필요한 데이터**:
- 기업 기본 정보 (이름, 산업, 거래소, 설립일)
- 제품 라인 (주요 제품, 기술)
- 재무 지표 (시가총액, 매출, 이익)
- 산업 구조 (밸류체인, 경쟁 관계)

**데이터 소스**:
- DART API (기업 정보, 재무제표)
- 네이버/다음 금융 (주가, 기본 재무 정보)
- 기업 IR 자료 (제품 정보)

#### 2. 동적 데이터 (Dynamic Data) - Event Graph 구축용

**목적**: 시간에 민감한 이벤트 정보 저장

**필요한 데이터**:
- 실적 발표 (분기별 실적, 가이던스)
- 주요 공시 (M&A, 투자, 신제품 출시)
- 뉴스 및 이벤트 (규제 변화, 시장 동향)
- 시장 감성 (뉴스 감성, 분석가 리포트)

**데이터 소스**:
- DART API (주요 경영사항)
- 뉴스 API (기업 관련 뉴스)
- 증권 리포트 (분석가 의견)

### FinKario의 데이터 수집 방법

FinKario 논문에서는 다음과 같은 데이터 소스를 활용했습니다:

1. **증권 리포트**: East Money 웹사이트에서 수집
2. **재무 데이터**: Tushare 플랫폼으로 속성 보완
3. **뉴스**: Bloomberg, Yahoo, EODHD, FinnHub
4. **소셜 미디어**: Reddit, Twitter (감성 분석용)

### 1. DART (Data Analysis, Retrieval and Transfer System) - 최우선

**제공 기관**: 금융감독원 전자공시시스템

**웹사이트**: https://opendart.fss.or.kr/

**API 키 발급**:
1. 웹사이트 회원가입 (무료)
2. API 인증키 발급
3. 일일 호출 제한: 10,000건

#### 제공 데이터

**1. 기업 기본 정보**
- 기업명, 영문명, 법인등록번호
- 대표자명, 업종코드, 설립일
- 본사 주소, 홈페이지
- 상장일, 거래소 정보

**2. 재무제표**
- 손익계산서 (매출, 영업이익, 당기순이익)
- 재무상태표 (자산, 부채, 자본)
- 현금흐름표 (영업, 투자, 재무 활동)
- 분기별/연간 데이터

**3. 주요 경영사항**
- 실적 발표
- 가이던스 변경
- 투자 결정
- M&A
- 신제품 출시
- 임원 변경

#### API 사용법

```python
import requests
from datetime import datetime, timedelta

class DARTAPI:
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = "https://opendart.fss.or.kr/api"
    
    def get_company_info(self, corp_code):
        """기업 기본 정보 조회"""
        url = f"{self.base_url}/company.json"
        params = {
            'crtfc_key': self.api_key,
            'corp_code': corp_code
        }
        response = requests.get(url, params=params)
        return response.json()
    
    def get_financial_statements(self, corp_code, bsns_year, reprt_code):
        """
        재무제표 조회
        
        reprt_code:
        - 11011: 사업보고서 (연간)
        - 11012: 반기보고서
        - 11013: 1분기보고서
        - 11014: 3분기보고서
        """
        url = f"{self.base_url}/fnlttSinglAcnt.json"
        params = {
            'crtfc_key': self.api_key,
            'corp_code': corp_code,
            'bsns_year': bsns_year,
            'reprt_code': reprt_code
        }
        response = requests.get(url, params=params)
        return response.json()
    
    def get_major_announcements(self, corp_code, bgn_de, end_de, page_no=1):
        """주요 경영사항 조회"""
        url = f"{self.base_url}/list.json"
        params = {
            'crtfc_key': self.api_key,
            'corp_code': corp_code,
            'bgn_de': bgn_de,  # YYYYMMDD
            'end_de': end_de,  # YYYYMMDD
            'page_no': page_no,
            'page_count': 100
        }
        response = requests.get(url, params=params)
        return response.json()
    
    def search_corp_code(self, corp_name):
        """기업명으로 기업 코드 검색"""
        url = f"{self.base_url}/company.json"
        params = {
            'crtfc_key': self.api_key,
            'corp_name': corp_name
        }
        response = requests.get(url, params=params)
        return response.json()

# 사용 예시

# 2. 기업 기본 정보

# 3. 재무제표 (2024년 3분기)

    corp_code="00126380",

)

# 4. 주요 경영사항 (최근 1년)
```

**수집 방법**:
```python
import requests
from bs4 import BeautifulSoup

class NaverFinance:
    def __init__(self):
        self.base_url = "https://finance.naver.com"
    
    def get_stock_info(self, stock_code):
        """주식 정보 조회"""
        url = f"{self.base_url}/item/main.naver?code={stock_code}"
        response = requests.get(url)
        soup = BeautifulSoup(response.text, 'html.parser')
        
        # 현재가
        current_price = soup.select_one(".no_today .blind").text
        
        # 시가총액
        market_cap = soup.select_one("#_market_sum").text
        
        # 재무 정보 테이블
        financial_table = soup.select("#content > div.section.invest_trend > div > table")
        
        return {
            'current_price': current_price,
            'market_cap': market_cap,
            # 추가 정보 파싱
        }
    
    def get_news(self, stock_code, page=1):
        """뉴스 조회"""
        url = f"{self.base_url}/item/news.naver?code={stock_code}&page={page}"
        response = requests.get(url)
        soup = BeautifulSoup(response.text, 'html.parser')
        
        news_list = []
        for news in soup.select(".newsList li"):
            title = news.select_one("a").text.strip()
            link = news.select_one("a")["href"]
            date = news.select_one(".date").text.strip()
            
            news_list.append({
                'title': title,
                'link': self.base_url + link,
                'date': date
            })
        
        return news_list
    
    def get_announcements(self, stock_code):
        """공시 조회"""
        url = f"{self.base_url}/item/board.naver?code={stock_code}"
        response = requests.get(url)
        soup = BeautifulSoup(response.text, 'html.parser')
        
        announcements = []
        for ann in soup.select(".type_1 tr"):
            if ann.select_one("td.title"):
                title = ann.select_one("td.title a").text.strip()
                date = ann.select_one("td.date").text.strip()
                announcements.append({'title': title, 'date': date})
        
        return announcements
```

```python
from mineru import PDFParser
import requests

class ReportCollector:
    def __init__(self):
        self.reports = []
    
    def download_report(self, report_url, save_path):
        """증권 리포트 PDF 다운로드"""
        response = requests.get(report_url)
        with open(save_path, 'wb') as f:
            f.write(response.content)
        return save_path
    
    def parse_pdf_to_markdown(self, pdf_path):
        """PDF를 Markdown으로 변환 (MinerU 사용)"""
        parser = PDFParser()
        markdown = parser.parse(pdf_path)
        
        # 정제: 면책 조항, 이미지, 반복 법적 문구 제거
        cleaned = self._clean_markdown(markdown)
        
        return cleaned
    
    def _clean_markdown(self, markdown):
        """마크다운 정제"""
        import re
        
        # 면책 조항 제거
        markdown = re.sub(r'면책.*?조항.*?\n', '', markdown, flags=re.DOTALL)
        
        # 이미지 참조 제거
        markdown = re.sub(r'!\[.*?\]\(.*?\)', '', markdown)
        
        # 반복 법적 문구 제거
        legal_phrases = [
            '본 보고서는.*?참고용',
            '투자 결정.*?책임',
            '저작권.*?보호'
        ]
        for phrase in legal_phrases:

        return markdown
```

#### PDF → Markdown 변환

```python
from mineru import PDFParser
import os

class ReportProcessor:
    def __init__(self):
        self.parser = PDFParser()
    
    def process_report(self, pdf_path, output_path=None):
        """리포트 PDF를 Markdown으로 변환"""
        
        # PDF 파싱
        markdown = self.parser.parse(pdf_path)
        
        # 정제
        cleaned = self._clean_markdown(markdown)
        
        # 저장
        if output_path:
            os.makedirs(os.path.dirname(output_path), exist_ok=True)
            with open(output_path, 'w', encoding='utf-8') as f:
                f.write(cleaned)
        
        return cleaned
    
    def _clean_markdown(self, markdown):
        """마크다운 정제"""
        import re
        
        # 1. 면책 조항 제거
        patterns_to_remove = [
            r'면책.*?조항.*?\n',
            r'본 보고서.*?참고용.*?\n',
            r'투자 결정.*?책임.*?\n',
            r'저작권.*?보호.*?\n'
        ]
        
        for pattern in patterns_to_remove:
            markdown = re.sub(pattern, '', markdown, flags=re.DOTALL | re.IGNORECASE)
        
        # 2. 이미지 참조 제거
        markdown = re.sub(r'!\[.*?\]\(.*?\)', '', markdown)
        
        # 3. 반복되는 헤더/푸터 제거
        markdown = re.sub(r'^.*?증권.*?리포트.*?\n', '', markdown, flags=re.MULTILINE)
        
        # 4. 빈 줄 정리
        markdown = re.sub(r'\n{3,}', '\n\n', markdown)
        
        return markdown

# 사용 예시
processor = ReportProcessor()

# 리포트 처리
markdown = processor.process_report(
    "data/raw/reports/samsung_report.pdf",
    "data/processed/reports/samsung_report.md"
)
```

```python
class DataValidator:
    def __init__(self):
        self.issues = []
    
    def validate_company_data(self, data):
        """기업 데이터 검증"""
        
        # 필수 필드 확인
        required_fields = ['company_name', 'ticker']
        for field in required_fields:
            if field not in data or not data[field]:
                self.issues.append(f"Missing required field: {field}")
        
        # 데이터 타입 확인
        if 'market_cap' in data:
            if not isinstance(data['market_cap'], (int, float)):
                self.issues.append("market_cap should be numeric")
            elif data['market_cap'] <= 0:
                self.issues.append("market_cap should be positive")
        
        # 이상치 확인
        if 'revenue' in data and data['revenue'] < 0:
            self.issues.append("Revenue cannot be negative")
        
        if 'pe_ratio' in data and data['pe_ratio'] < 0:
            self.issues.append("P/E ratio cannot be negative")
        
        return {
            'is_valid': len(self.issues) == 0,
            'issues': self.issues
        }
    
    def validate_financial_data(self, financial_data):
        """재무 데이터 검증"""
        
        issues = []
        
        # 필수 항목 확인
        required_items = ['revenue', 'operating_profit', 'net_income']
        for item in required_items:
            if item not in financial_data:
                issues.append(f"Missing financial item: {item}")
        
        # 논리적 일관성 확인
        if 'operating_profit' in financial_data and 'revenue' in financial_data:
            if financial_data['operating_profit'] > financial_data['revenue']:
                issues.append("Operating profit cannot exceed revenue")
        
        if 'net_income' in financial_data and 'operating_profit' in financial_data:
            if financial_data['net_income'] > financial_data['operating_profit'] * 1.5:
                issues.append("Net income seems unusually high compared to operating profit")
        
        return {
            'is_valid': len(issues) == 0,
            'issues': issues
        }
    
    def normalize_company_name(self, name):
        """기업명 정규화"""
        # 변형된 이름을 표준 형태로 변환
        name_variants = {
            '삼성전자(주)': '삼성전자',
            '삼성전자 주식회사': '삼성전자',
            'SK하이닉스(주)': 'SK하이닉스',
            # 추가 변형...
        }
        
        return name_variants.get(name, name)
```

```python
def quality_control_pipeline(collected_data):
    """데이터 품질 관리 파이프라인"""
    
    validator = DataValidator()
    cleaned_data = {}

        # 1. 검증

    if 'market_cap' not in data and 'ticker' in data:
        try:
            stock = yf.Ticker(f"{data['ticker']}.KS")
            info = stock.info
            data['market_cap'] = info.get('marketCap')
        except:
            pass
    
    return data
```

## 데이터 수집 시 주의사항

### 1. API 사용 제한

**DART API**:
- 일일 호출 제한: 10,000건
- 초당 호출 제한: 없음 (하지만 과도한 호출 자제)

**대응 방법**:
```python
import time

def rate_limited_api_call(api_func, *args, **kwargs):
    """Rate limit을 고려한 API 호출"""
    result = api_func(*args, **kwargs)
    time.sleep(0.1)  # 100ms 대기
    return result
```

**Yahoo Finance**:
- 공식 API 제한 없음
- 하지만 과도한 요청 시 IP 차단 가능

**대응 방법**:
```python
import time
from random import uniform

def safe_yahoo_request(ticker):
    """안전한 Yahoo Finance 요청"""
    try:
        stock = yf.Ticker(ticker)
        data = stock.history(period="1y")
        time.sleep(uniform(0.5, 1.5))  # 랜덤 대기
        return data
    except Exception as e:
        print(f"요청 실패: {e}")
        time.sleep(5)  # 에러 시 더 긴 대기
        return None
```

### 2. 저작권 및 이용약관

**공시 자료 (DART)**:
- ✅ 공개 자료이므로 자유롭게 사용 가능
- ✅ 상업적 용도도 가능 (이용약관 확인 필요)

**증권 리포트**:
- ⚠️ 저작권 보호

- ✅ 출처 명시 필요

**뉴스 기사**:
- ⚠️ 저작권 보호
- ✅ 출처 명시 필요
- ⚠️ 대량 수집 시 이용약관 확인

**대응 방법**:
- 공시 자료는 DART API 사용 (공식, 안전)
- 리포트는 개인 학습/연구 목적으로만 사용
- 뉴스는 출처 명시하고 제한적으로 수집

### 3. 데이터 품질 관리

```python
def validate_collected_data(data):
    """수집된 데이터 종합 검증"""
    
    validator = DataValidator()
    issues = []
    
    # 1. 필수 필드 확인
    required = ['company_name', 'ticker']
    for field in required:
        if field not in data:
            issues.append(f"Missing: {field}")
    
    # 2. 데이터 타입 확인
    numeric_fields = ['market_cap', 'revenue', 'pe_ratio']
    for field in numeric_fields:
        if field in data and not isinstance(data[field], (int, float)):
            issues.append(f"Invalid type: {field}")
    
    # 3. 이상치 확인
    if 'pe_ratio' in data:
        if data['pe_ratio'] > 100 or data['pe_ratio'] < 0:
            issues.append(f"Suspicious P/E ratio: {data['pe_ratio']}")
    
    # 4. 일관성 확인
    if 'revenue' in data and 'operating_profit' in data:
        if data['operating_profit'] > data['revenue']:
            issues.append("Operating profit exceeds revenue (inconsistent)")
    
    return {
        'is_valid': len(issues) == 0,
        'issues': issues
    }
```

## 실전 수집 스크립트 예시

### 완전한 데이터 수집 스크립트

다음 코드를 `scripts/collect_data.py`로 저장하세요:

```python
#!/usr/bin/env python3
"""
한국 반도체 섹터 데이터 수집 스크립트
"""

from datetime import datetime, timedelta
import json
import os
import time
from dotenv import load_dotenv
import yfinance as yf
import requests

load_dotenv()

class KoreanSemiconductorDataCollector:
    def __init__(self):
        self.dart_api_key = os.getenv("DART_API_KEY")
        self.collected_data = {}
        
        if not self.dart_api_key:
            print("⚠️ DART_API_KEY가 .env 파일에 없습니다.")
            print("   DART API 없이 Yahoo Finance만 사용합니다.")
    
    def collect_all(self, companies):
        """모든 데이터 수집"""
        
        print("=" * 50)
        print("한국 반도체 섹터 데이터 수집 시작")
        print("=" * 50)
        
        for i, company in enumerate(companies, 1):
            print(f"\n[{i}/{len(companies)}] {company['name']} 수집 중...")
            
            data = {
                'company_name': company['name'],
                'ticker': company['ticker'],
                'collected_at': datetime.now().isoformat()
            }
            
            # 1. Yahoo Finance 주가 및 재무 정보
            print("  - Yahoo Finance 데이터 수집...")
            stock_data = self._get_yahoo_data(company['ticker'])
            if stock_data:
                data.update(stock_data)
            
            # 2. DART 기본 정보
            if self.dart_api_key and company.get('corp_code'):
                print("  - DART 기본 정보 수집...")
                dart_info = self._get_dart_info(company['corp_code'])
                if dart_info:
                    data['dart_info'] = dart_info
            
            # 3. DART 재무제표
            if self.dart_api_key and company.get('corp_code'):
                print("  - DART 재무제표 수집...")
                financials = self._get_dart_financials(company['corp_code'])
                if financials:
                    data['financials'] = financials
            
            # 4. DART 공시
            if self.dart_api_key and company.get('corp_code'):
                print("  - DART 공시 수집...")
                announcements = self._get_dart_announcements(company['corp_code'])
                if announcements:
                    data['announcements'] = announcements
            
            self.collected_data[company['name']] = data
            print(f"  ✅ {company['name']} 수집 완료")
            
            # Rate limiting
            time.sleep(1)
        
        return self.collected_data
    
    def _get_yahoo_data(self, ticker):
        """Yahoo Finance 데이터"""
        try:
            stock = yf.Ticker(f"{ticker}.KS")
            info = stock.info
            history = stock.history(period="1y")
            
            return {
                'current_price': history['Close'].iloc[-1] if not history.empty else None,
                'market_cap': info.get('marketCap'),
                'pe_ratio': info.get('trailingPE'),
                'pb_ratio': info.get('priceToBook'),
                'roe': info.get('returnOnEquity'),
                'revenue': info.get('totalRevenue'),
                'operating_income': info.get('operatingIncome'),
                'net_income': info.get('netIncomeToCommon'),
                'sector': info.get('sector'),
                'industry': info.get('industry')
            }
        except Exception as e:
            print(f"    ⚠️ Yahoo Finance 오류: {e}")
            return None
    
    def _get_dart_info(self, corp_code):
        """DART 기업 정보"""
        try:
            url = "https://opendart.fss.or.kr/api/company.json"
            params = {'crtfc_key': self.dart_api_key, 'corp_code': corp_code}
            response = requests.get(url, params=params, timeout=10)
            
            if response.status_code == 200:
                return response.json()
        except Exception as e:
            print(f"    ⚠️ DART 정보 오류: {e}")
        return None
    
    def _get_dart_financials(self, corp_code):
        """DART 재무제표"""
        current_year = datetime.now().year
        financials = {}
        
        quarters = {"11011": "연간", "11014": "3Q", "11012": "반기", "11013": "1Q"}
        
        for code, name in quarters.items():
            try:
                url = "https://opendart.fss.or.kr/api/fnlttSinglAcnt.json"
                params = {
                    'crtfc_key': self.dart_api_key,
                    'corp_code': corp_code,
                    'bsns_year': str(current_year),
                    'reprt_code': code
                }
                response = requests.get(url, params=params, timeout=10)
                
                if response.status_code == 200:
                    result = response.json()
                    if result.get('status') == '000':
                        financials[name] = result
                
                time.sleep(0.2)
            except Exception as e:
                continue
        
        return financials if financials else None
    
    def _get_dart_announcements(self, corp_code):
        """DART 공시"""
        try:
            end_date = datetime.now().strftime("%Y%m%d")
            start_date = (datetime.now() - timedelta(days=365)).strftime("%Y%m%d")
            
            url = "https://opendart.fss.or.kr/api/list.json"
            params = {
                'crtfc_key': self.dart_api_key,
                'corp_code': corp_code,
                'bgn_de': start_date,
                'end_de': end_date,
                'page_count': 100
            }
            response = requests.get(url, params=params, timeout=10)
            
            if response.status_code == 200:
                result = response.json()
                if result.get('status') == '000':
                    return result.get('list', [])
        except Exception as e:
            print(f"    ⚠️ DART 공시 오류: {e}")
        return None
    
    def save(self, filepath="data/raw/collected_data.json"):
        """데이터 저장"""
        os.makedirs(os.path.dirname(filepath), exist_ok=True)
        with open(filepath, 'w', encoding='utf-8') as f:
            json.dump(self.collected_data, f, ensure_ascii=False, indent=2)
        print(f"\n✅ 데이터 저장 완료: {filepath}")

if __name__ == "__main__":
    collector = KoreanSemiconductorDataCollector()
    
    # 수집할 기업 목록
    companies = [
        {"name": "삼성전자", "corp_code": "00126380", "ticker": "005930"},
        {"name": "SK하이닉스", "corp_code": "00164742", "ticker": "000660"},
        {"name": "DB하이텍", "corp_code": "00164742", "ticker": "000990"},
    ]
    
    # 데이터 수집
    data = collector.collect_all(companies)
    
    # 저장
    collector.save("data/raw/semiconductor_companies.json")
    
    print("\n" + "=" * 50)
    print("데이터 수집 완료!")
    print("=" * 50)
```
