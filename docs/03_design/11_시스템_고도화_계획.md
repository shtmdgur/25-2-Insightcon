## 개요 및 목표

### 현재 시스템 한계

현재 시스템(v0.1.0)은 기본적인 멀티 에이전트 워크플로우를 갖추고 있으나, 다음과 같은 한계가 있습니다:

1. **데이터 처리**: PDF 이미지/차트 정보 손실, CSV 데이터 비효율적 처리
2. **엔티티 정규화**: 동일 기업의 다양한 표기(삼성/삼성전자/Samsung) 미통합
3. **관계 추출**: 단순한 관계 매핑 (모든 제품을 모든 기업에 연결)
4. **시계열 통합**: 동적 데이터(뉴스, 이벤트, 주가 패턴) 미반영
5. **검색 품질**: 단순 Cypher 쿼리, Multi-hop Traversal 부재
6. **추론 고도화**: 단일 관점 분석, 변증법적 토론 부재
7. **설명 가능성**: 근거 추적 미흡, 시각화 부재

### 고도화 목표

**금융 특화 Knowledge Graph RAG** 시스템을 구축하여:

- 정적 데이터(리포트, 재무제표)와 동적 데이터(뉴스, 시계열)를 통합
- Seed 온톨로지 기반 정확한 엔티티/관계 추출
- Multi-hop 검색 및 변증법적 에이전트 토론을 통한 심층 분석
- 투명한 근거 제시 및 시각적 설명 가능성 확보

### Knowledge Graph 이중 레이어 아키텍처

본 시스템은 **정적 KG (Static Core Ontology)**와 **동적 KG (Temporal Layer)**의 이중 구조로 설계됩니다.

#### 🏗️ 아키텍처 개요

```
┌─────────────────────────────────────────────────────┐
│           Knowledge Graph (Neo4j)                    │
├─────────────────────────────────────────────────────┤
│                                                      │
│  ┌──────────────────┐      ┌───────────────────┐   │
│  │   정적 KG Layer  │      │   동적 KG Layer   │   │
│  │  (Static Core)   │◄────►│  (Temporal)       │   │
│  └──────────────────┘      └───────────────────┘   │
│         ▲                           ▲               │
│         │                           │               │
│    온톨로지, 구조          이벤트, 시계열, 트렌드    │
│    변화 빈도: 낮음         변화 빈도: 높음           │
└─────────────────────────────────────────────────────┘
```

#### 📐 분류 기준 (3가지)

| 기준 | 정적 KG (Static) | 동적 KG (Dynamic) |
|------|------------------|-------------------|
| **시간 속성 유무** | 불필요 또는 생성일만 | **필수** (date, period 속성) |
| **변화 빈도** | 거의 안 변함 (연 1~2회) | 자주 변함 (일/주/월 단위) |
| **노드 타입** | Company, Product, Technology, Person | Metric, Event, Trend, TimeSeries |

#### 🎯 데이터 소스별 분류

| 데이터 | 정적 KG | 동적 KG | 판단 근거 |
|--------|---------|---------|-----------|
| **DART companies** | ✅ Company 노드 | - | 기업 정보는 불변 |
| **DART financials** | - | ✅ Metric (분기별) | period 속성 필수 |
| **reports (PDF)** | ✅ Company, Product | ✅ Metric, Event, Trend | LLM이 시간 속성 유무로 판단 |
| **news** | - | ✅ Event | date 속성 필수 |
| **price/SAX** | - | ✅ TimeSeries, Trend | 시계열 데이터 |
| **fund** | ✅ 정적 속성 (industry) | ✅ 동적 지표 (ROE, P/E) | 속성별 구분 |

#### ⚙️ Neo4j 주입 전략

**정적 엔티티**: `MERGE` (ID 기준 UPSERT)
```cypher
// 동일 ID면 속성만 업데이트
MERGE (n:Company {id: $id})
SET n.name = $name,
    n += $properties,
    n.updated_at = datetime()
```

**동적 엔티티**: `CREATE` (period/date별 새 노드)
```cypher
// 매번 새 노드 생성 (시계열)
CREATE (n:Metric {
    id: "Revenue_005930_2024Q4",  // period 포함
    name: $name,
    period: "2024Q4"  // 필수
})
SET n += $properties,
    n.created_at = datetime()
```

**Time-Decay 가중치** (동적 관계):
```python
def calculate_time_decay(date_str: str, half_life_days: int = 90) -> float:
    """
    시간 감쇠 함수 (최근 데이터일수록 높은 가중치)
    
    Args:
        date_str: 이벤트 날짜
        half_life_days: 반감기 (기본 90일)
    
    Returns:
        0.1 ~ 1.0 (최근일수록 1.0)
    """
    days_diff = (datetime.now() - datetime.fromisoformat(date_str)).days
    decay = np.exp(-days_diff / half_life_days)
    return max(decay, 0.1)

// Neo4j 관계에 적용
MERGE (e)-[:AFFECTS {
    weight: $importance,
    time_decay: $time_decay,
    effective_weight: $importance * $time_decay
}]->(c)
```

```python
class GeminiPDFParser:
    def __init__(self, model_name: str = "gemini-2.5-pro", use_batch: bool = False):
        self.model_name = model_name
        self.use_batch = use_batch
    
    def parse(self, file_path: str) -> dict:
        """
        PDF를 Gemini로 직접 분석하여 Knowledge Graph JSON 추출
        
        Returns:
            {
                "knowledge_graph": KnowledgeGraph,  # Pydantic 모델
                "raw_json": dict,
                "metadata": {
                    "parser": "Gemini-PDF-Native",
                    "entity_count": 154,
                    "relation_count": 97
                }
            }
        """
        # 1. Files API로 PDF 업로드
        file_ref = self.gemini_client.files.upload(file=file_path)
        
        # 2. Structured Output으로 KG 추출
        response = self.gemini_client.models.generate_content(
            model=self.model_name,
            contents=[file_ref, self.prompt],
            config={
                "response_mime_type": "application/json",
                "response_schema": KnowledgeGraph
            }
        )
        
        return {
            "knowledge_graph": KnowledgeGraph.model_validate_json(response.text),
            "raw_json": response.text,
            "metadata": {...}
        }
```

```python
# src/dataflows/neo4j_loader.py

class Neo4jKGLoader:
    def load_knowledge_graph(self, kg: KnowledgeGraph) -> Dict[str, int]:
        """
        Knowledge Graph를 Neo4j에 UPSERT 방식으로 로드
        
        전략:
        - MERGE를 사용하여 기존 노드/관계가 있으면 업데이트, 없으면 생성
        - 데이터 누적 방식으로 기존 그래프 보존
        """
        # 엔티티(노드) 생성
        for entity in kg.entities:
            query = f"""
            MERGE (n:`{entity.label}` {{id: $id}})
            SET n.name = $name
            SET n += $properties
            RETURN n
            """
            session.run(query, id=entity.id, name=entity.name, properties=props)
        
        # 관계(엣지) 생성
        for relation in kg.relations:
            query = f"""
            MATCH (source {{id: $source_id}})
            MATCH (target {{id: $target_id}})
            MERGE (source)-[r:`{relation.type}`]->(target)
            SET r += $properties
            RETURN r
            """
            session.run(query, source_id=..., target_id=..., properties=...)
```

```
`KGConstructionAgent`는 `data/raw/` 디렉토리를 탐색할 때 다음 규칙(Glob Pattern)을 사용하여 파일을 식별합니다.

| 소스 타입 | 스캔 경로 및 패턴 | 비고 |
|-----------|-------------------|------|
| **PDF** | `reports/**/*.pdf`, `ir/**/*.pdf` | 하위 폴더 재귀 스캔 |
| **Price** | `price/*.csv` | 주가 시계열 데이터 |
| **DART** | `DART/` (디렉토리) | 공시 데이터 루트 |

| **Macro** | `macro/*.csv` | 거시경제 지표 |
| **Fund** | `fund/*_fundamentals.csv` | 기업 펀더멘탈 데이터 |
```

**KGConstructionAgent 역할**:
1. **데이터 소스 자동 스캔** - `data/raw/*` 디렉토리 탐색
2. **Parser Agent 선택** - 파일 타입별 적절한 파서 매핑
3. **병렬 실행 오케스트레이션** - 여러 파서 동시 실행
4. **JSON 수집 및 병합** - KGMerger 사용
5. **Entity 정규화** - EntityNormalizer 통합
6. **Neo4j 주입** - Neo4jKGLoader 호출
7. **결과 리포트** - 통계 및 로그 생성

```python
        self.pdf_parser_agent = PDFParserAgent()
        self.price_parser_agent = PriceParserAgent()
        self.dart_parser_agent = DARTParserAgent()
        
        # 유틸리티
        self.merger = KGMerger()
        self.normalizer = EntityNormalizer()
        self.loader = Neo4jKGLoader()
    
    def construct_knowledge_graph(
        self, 
        data_sources: Optional[Dict] = None,
        auto_scan: bool = True
    ) -> Dict:
        """전체 KG 구축 파이프라인"""
        # 1. 데이터 소스 수집
        if auto_scan:
            data_sources = self._scan_data_sources()
        
        # 2. Parser Agents 실행 (병렬)
        parsing_results = self._orchestrate_parsers(data_sources)
        
        # 3. JSON 병합
        json_files = self._collect_json_files()
        merged_kg = self._merge_and_refine(json_files)
        
        # 4. Neo4j 주입
        load_stats = self._load_to_neo4j(merged_kg)
        
        return self._generate_report(parsing_results, load_stats)
```

```python
class PDFParserAgent:
    def __init__(self):
        self.parser = GeminiPDFParser()
    
    def parse_batch(self, pdf_files: List[Path]) -> Dict:
        """여러 PDF 파일 배치 파싱"""
        results = []
        for pdf_file in pdf_files:
            try:
                result = self.parser.parse(str(pdf_file))
                results.append({
                    "file": pdf_file.name,
                    "status": "success",
                    "json_path": result["metadata"]["json_path"]
                })
            except Exception as e:
                results.append({
                    "file": pdf_file.name,
                    "status": "failed",
                    "error": str(e)
                })
        return results
```

```python
class PriceParserAgent:
    def parse_batch(self, csv_files: List[Path]) -> Dict:
        """주가 CSV를 직접 Neo4j에 주입"""
        for csv_file in csv_files:
            df = pd.read_csv(csv_file)

                    name=row['company']

                self.loader.create_metric(
                    company_ticker=row['ticker'],
                    metric_type="Price",
                    period=row['date'],
                    value=row['close']
                )
```

```python
# src/utils/entity_normalizer.py

import pandas as pd
from neo4j import GraphDatabase

class EntityNormalizer:
    def __init__(self, neo4j_client):
        self.neo4j = neo4j_client
        self.master_data = self._load_master_data()
    
    def _load_master_data(self) -> pd.DataFrame:
        """
        KRX 상장사 리스트 로드
        
        CSV 예시:
        ticker,name,name_en,aliases
        005930,삼성전자,Samsung Electronics,"삼성,Samsung,SEC"
        000660,SK하이닉스,SK Hynix,"하이닉스,Hynix"
        """
        return pd.read_csv("data/master/krx_companies.csv")
    
    def normalize_entity(self, mention: str) -> dict:
        """
        텍스트 멘션을 표준 엔티티로 매핑
        
        Returns:
            {
                "canonical_name": "삼성전자",
                "ticker": "005930",
                "aliases": ["삼성", "Samsung"],
                "confidence": 0.95
            }
        """
        # 1. Exact Match (Ticker 또는 정확한 이름)
        exact_match = self.master_data[
            (self.master_data['ticker'] == mention) |
            (self.master_data['name'] == mention) |
            (self.master_data['name_en'] == mention)
        ]
        
        if not exact_match.empty:
            return self._to_entity_dict(exact_match.iloc[0], confidence=1.0)
        
        # 2. Fuzzy Matching (철자 유사도)
        fuzzy_matches = self._fuzzy_search(mention)
        if fuzzy_matches:
            return fuzzy_matches[0]  # 가장 유사도 높은 것
        
        # 3. Vector Similarity (의미 유사도)
        semantic_match = self._semantic_search(mention)
        return semantic_match
    
    def _fuzzy_search(self, mention: str) -> List[dict]:
        """Levenshtein Distance 기반 유사도"""
        from fuzzywuzzy import fuzz
        
        matches = []
        for _, row in self.master_data.iterrows():
            score = max(
                fuzz.ratio(mention, row['name']),
                fuzz.ratio(mention, row['name_en'])
            )
            if score > 80:  # 임계값
                matches.append(self._to_entity_dict(row, confidence=score/100))
        
        return sorted(matches, key=lambda x: x['confidence'], reverse=True)
    
    def _semantic_search(self, mention: str) -> dict:
        """Embedding 기반 의미 유사도"""
        # OpenAI Embeddings 또는 한국어 SBERT 사용
        from langchain_openai import OpenAIEmbeddings
        
        embeddings = OpenAIEmbeddings()
        mention_vec = embeddings.embed_query(mention)
        
        # 미리 계산된 Master Data Embedding과 비교
        # (사전에 prepare_embeddings()로 계산)
        similarities = self._cosine_similarity(mention_vec, self.master_embeddings)
        
        best_idx = np.argmax(similarities)
        return self._to_entity_dict(
            self.master_data.iloc[best_idx],
            confidence=similarities[best_idx]
        )
```

```python
def calculate_time_decay(event_date: datetime, current_date: datetime) -> float:
    """
    최근 이벤트일수록 가중치 ↑
    
    예: 1개월 전 = 0.9, 6개월 전 = 0.5, 1년 전 = 0.2
```

### 2.2 Multi-hop Retrieval

#### Graph Traversal 전략

```python
# src/pipeline/graphrag_query.py

class MultiHopGraphRAG:
    def __init__(self, neo4j_client, llm):
        self.neo4j = neo4j_client
        self.llm = llm
    
    def multi_hop_search(self, query: str, max_hops: int = 2):
        """
        단계적 그래프 탐색
        
        예: "SK하이닉스의 주요 경쟁사와 그들의 최근 이슈는?"
        - Hop 1: SK하이닉스 → COMPETITOR_OF → 삼성전자
        - Hop 2: 삼성전자 → AFFECTED_BY → Event (HBM3 양산)
        """
        # 1. Anchor Entity 식별
        anchor_entities = self._extract_entities_from_query(query)
        
        # 2. 1-Hop 확장
        hop1_results = self._expand_1hop(anchor_entities, query)
        
        # 3. Path Filtering (불필요한 관계 제거)
        filtered_paths = self._filter_irrelevant_paths(hop1_results, query)
        
        # 4. 2-Hop 확장 (필요 시)
        if self._needs_further_expansion(filtered_paths, query):
            hop2_results = self._expand_2hop(filtered_paths, query)
            return hop2_results
        
        return filtered_paths
    
    def _expand_1hop(self, anchor_entities: List[str], query: str):
        """
        1-Hop 확장 (직접 연결된 노드)
        """
        cypher = """
        UNWIND $anchors AS anchor_name
        MATCH (anchor {name: anchor_name})-[r]-(neighbor)
        RETURN anchor, type(r) AS rel_type, neighbor
        """
        
        results = self.neo4j.query(cypher, {"anchors": anchor_entities})
        return results
    
    def _filter_irrelevant_paths(self, paths: List, query: str):
        """
        LLM으로 관련 없는 경로 제거
        """
        filtered = []
        for path in paths:
            if self._is_relevant_path(path, query):
                filtered.append(path)
        
        return filtered
    
    def _is_relevant_path(self, path: dict, query: str) -> bool:
        """
        경로 relevance 판단
        """
        prompt = f"""
        질문: {query}
        경로: {path['anchor']['name']} -[{path['rel_type']}]-> {path['neighbor']['name']}
        
        이 경로가 질문과 관련 있습니까? Yes/No
        """
        
        response = self.llm.invoke(prompt)
        return "Yes" in response.content
```

```python
# src/agents/dialectical_agents.py

from langgraph.graph import StateGraph, END
from typing import TypedDict

class DebateState(TypedDict):
    query: str
    graphrag_results: dict
    bull_argument: str
    bear_argument: str
    synthesis: str

class BullAgent:
    """긍정론자 (매수 논리)"""
    
    def __init__(self, llm):
        self.llm = llm
    
    def argue(self, query: str, data: dict) -> dict:
        """
        긍정론 생성 (온톨로지 기반 동적 논거)
        
        Returns:
            {
                "argument": "상세 주장",
                "key_points": ["동적 생성된 핵심 논거 1", "논거 2", ...]
            }
        """
        # 온톨로지에서 긍정적 요소 추출
        positive_events = self._extract_positive_events(data)
        upward_trends = self._extract_upward_trends(data)
        growth_metrics = self._extract_growth_metrics(data)
        
        prompt = f"""
        당신은 낙관적 투자 분석가입니다.
        
        질문: {query}
        
        데이터 (GraphRAG 결과):
        - 긍정적 이벤트: {positive_events}
        - 상승 트렌드 (SAX): {upward_trends}
        - 성장 지표: {growth_metrics}
        
        다음 형식으로 매수 논리를 전개하세요:
        
        1. **상세 주장**: (온톨로지 데이터를 기반으로 구체적이고 설득력 있는 주장을 작성하십시오.)
        
        2. **핵심 논거**: (위 데이터에서 발견된 실제 호재를 바탕으로 3~5개의 핵심 논거를 생성하십시오.)
           - 예: "HBM3E 양산 개시로 AI 반도체 수요 선점" (Event 기반)
           - 예: "3분기 연속 매출 상승 추세 (SAX: abc)" (Trend 기반)
           - 예: "영업이익률 전년 대비 15% 개선" (Metric 기반)
        
        JSON 형식으로 반환:
        {{
            "argument": "상세 주장",
            "key_points": ["핵심 논거 1", "핵심 논거 2", "핵심 논거 3"]
        }}
        """
        
        response = self.llm.invoke(prompt)
        
        # JSON 파싱
        import json
        try:
            result = json.loads(response.content)
        except:
            # 파싱 실패 시 폴백
            result = {
                "argument": response.content,
                "key_points": ["데이터 기반 주장 (파싱 실패)"]
            }
        
        return result
    
    def _extract_positive_events(self, data: dict) -> list:
        """긍정적 이벤트 추출 (Event 노드에서)"""
        events = data.get('event_data', [])
        positive = [
            e for e in events 
            if e.get('sentiment', 'neutral') in ['positive', 'bullish']
        ]
        return [e['description'] for e in positive[:5]]  # 상위 5개
    
    def _extract_upward_trends(self, data: dict) -> list:
        """상승 트렌드 추출 (SAX 패턴)"""
        trends = data.get('trend_data', {})
        upward = [
            f"{ticker}: {info['pattern']}"
            for ticker, info in trends.items()
            if info.get('pattern') == 'Upward'
        ]
        return upward
    
    def _extract_growth_metrics(self, data: dict) -> list:
        """성장 지표 추출 (Metric 노드에서)"""
        metrics = data.get('financial_performance', {})
        growth = []
        
        # YoY 성장률 계산 예시
        if 'revenue_2024' in metrics and 'revenue_2023' in metrics:
            growth_rate = ((metrics['revenue_2024'] - metrics['revenue_2023']) / metrics['revenue_2023']) * 100
            if growth_rate > 0:
                growth.append(f"매출 YoY {growth_rate:.1f}% 성장")
        
        return growth

class BearAgent:
    """부정론자 (매도 논리)"""
    
    def __init__(self, llm):
        self.llm = llm
    
    def argue(self, query: str, data: dict) -> dict:
        """
        부정론 생성 (온톨로지 기반 동적 논거)

            {
                "argument": "상세 주장",

        1. **상세 주장**: (온톨로지 데이터를 기반으로 구체적이고 설득력 있는 주장을 작성하십시오.)

        {{
            "argument": "상세 주장",

        response = self.llm.invoke(prompt)

        try:

                "key_points": ["데이터 기반 주장 (파싱 실패)"]
            }

        trends = data.get('trend_data', {})
        downward = [
            f"{ticker}: {info['pattern']}"
            for ticker, info in trends.items()
            if info.get('pattern') in ['Downward', 'Volatile']
        ]
        return downward
    
    def _extract_risk_metrics(self, data: dict) -> list:
        """리스크 지표 추출"""
        metrics = data.get('financial_performance', {})
        risks = []
        
        # 부채비율 증가 예시
        if 'debt_ratio_2024' in metrics and 'debt_ratio_2023' in metrics:
            change = metrics['debt_ratio_2024'] - metrics['debt_ratio_2023']
            if change > 0:
                risks.append(f"부채비율 {change:.1f}%p 증가")

</div>

    def synthesize(
        self, 
        query: str, 
        bull_result: dict,  # {"argument": "...", "key_points": [...]}
        bear_result: dict,  # {"argument": "...", "key_points": [...]}
        data: dict,
        graph_paths: Optional[List] = None,
        graph_file_path: Optional[str] = None
    ) -> str:
        """
        한화투자증권 스타일 종합 리포트 생성
        
        Args:
            query: 사용자 질의
            bull_result: Bull Agent 결과 (dict with argument and key_points)
            bear_result: Bear Agent 결과 (dict with argument and key_points)
            data: GraphRAG 결과 및 분석 데이터
            graph_paths: Graph 경로 (Provenance)
            graph_file_path: PyVis HTML 파일 경로
        
        Returns:
            한화투자증권 스타일 마크다운 리포트
        """
        # Bull/Bear 결과 언패킹
        bull_arg = bull_result.get('argument', bull_result) if isinstance(bull_result, dict) else bull_result
        bull_points = bull_result.get('key_points', []) if isinstance(bull_result, dict) else []
        
        bear_arg = bear_result.get('argument', bear_result) if isinstance(bear_result, dict) else bear_result
        bear_points = bear_result.get('key_points', []) if isinstance(bear_result, dict) else []
        
        # 핵심 논거 포맷팅 (Bullet Points)
        bull_key_points_formatted = '\n'.join([f"- {point}" for point in bull_points])
        bear_key_points_formatted = '\n'.join([f"- {point}" for point in bear_points])
        
        # Graph Paths 포맷팅
        formatted_paths = self._format_critical_paths(graph_paths) if graph_paths else "N/A"
        
        # 프롬프트 구성
        user_prompt = f"""
질문: {query}

긍정론 (Bull Argument):
{bull_arg}

긍정론 핵심 논거 (온톨로지 기반):
{bull_key_points_formatted}

부정론 (Bear Argument):
{bear_arg}

부정론 핵심 논거 (온톨로지 기반):
{bear_key_points_formatted}

데이터 (GraphRAG Results):
{data}

핵심 연결 경로 (Critical Paths):
{formatted_paths}

Graph 시각화 파일: {graph_file_path or 'N/A'}

위 정보를 바탕으로 한화투자증권 스타일의 전문적인 투자 분석 리포트를 작성하세요.
반드시 [리포트 구조 템플릿]을 준수하십시오.

**중요**: Bull과 Bear의 핵심 논거는 위에 제공된 온톨로지 기반 논거를 그대로 사용하십시오. 임의로 변경하지 마십시오.
"""
        
        # LLM 호출
        messages = [
            {"role": "system", "content": self.system_prompt},
            {"role": "user", "content": user_prompt}
        ]
        
        response = self.llm.invoke(messages)
        return response.content
    
    def _format_critical_paths(self, paths: List) -> str:
        """
        Graph Path를 한화투자증권 스타일로 포맷팅
        
        예시: **[Path 1]**: `(삼성전자) --[COMPETITOR_OF]--> (SK하이닉스) --[AFFECTS]--> (HBM3 양산)`
        """
        formatted = []
        for i, path in enumerate(paths[:5], 1):  # 상위 5개만
            path_elements = []
            for j, node in enumerate(path):
                if j % 2 == 0:  # 엔티티
                    path_elements.append(f"({node.get('name', node.get('type'))})")
                else:  # 관계
                    path_elements.append(f"--[{node.get('type')}]-->")
            
            path_str = " ".join(path_elements)
            formatted.append(f"* **[Path {i}]**: `{path_str}`")
        
        return '\n'.join(formatted)
```

```python
debate_workflow.add_node("synthesizer", synthesizer_node)

debate_workflow.set_entry_point("bull")
debate_workflow.add_edge("bull", "bear")

# 조건부 라우팅: 최대 3라운드 토론 후 결론 도출
def route_debate(state):
    if state.get("debate_turn_count", 0) < 3:
        return "bull"  # 토론 계속 (Bull의 반박)
    return "synthesizer" # 토론 종료 및 종합

debate_workflow.add_conditional_edges(
    "bear",
    route_debate,
    {
        "bull": "bull",
        "synthesizer": "synthesizer"
    }
)
debate_workflow.add_edge("synthesizer", END)
debate_app = debate_workflow.compile()
```

```python
# src/pipeline/report_generation.py

class ExplainableReportGenerator:
    def generate_report_with_provenance(self, analysis: str, graph_paths: List):
        """
        분석 결과 + Graph Path 근거 포함
        """
        # Graph Path를 텍스트로 변환
        provenance = self._format_graph_path(graph_paths)
        
        report = f"""
        # 투자 분석 리포트
        
        ## 결론
        {analysis}
        
        ## 근거
        이 결론은 다음 연결 고리를 기반으로 도출되었습니다:
        
        {provenance}
        
        ## 출처
        {self._format_sources(graph_paths)}
        """
        
        return report
    
    def _format_graph_path(self, paths: List) -> str:
        """
        Graph Path를 가독성 높게 표현
        
        예: [삼성전자] -[COMPETITOR_OF]-> [SK하이닉스] -[AFFECTED_BY]-> [HBM3 양산]
        """
        formatted = []
        for path in paths:
            path_str = " -> ".join([
                f"[{node['name']}]" if i % 2 == 0 else f"-[{node['type']}]-"
                for i, node in enumerate(path)
            ])
            formatted.append(path_str)
        
        return "\n".join(formatted)
    
    def _format_sources(self, paths: List) -> str:
        """
        원문 링크 제공
        
        예: KB증권 리포트 5페이지, 매일경제 2024-12-01
        """
        sources = []
        for path in paths:
            for node in path:
                if 'source_doc' in node:
                    sources.append(f"- {node['source_doc']} (페이지 {node.get('page', 'N/A')})")
        
        return "\n".join(set(sources))  # 중복 제거
```

```python
# src/utils/report_formatter.py

import markdown
from weasyprint import HTML, CSS
from datetime import datetime
from typing import Dict, Optional
import jinja2

class HanwhaSecuritiesReportFormatter:
    """한화투자증권 스타일 리포트 생성기"""
    
    def __init__(self, template_path: str = "templates/hanwha_securities_template.md"):
        # Jinja2 템플릿 로더
        template_loader = jinja2.FileSystemLoader(searchpath="./templates")
        self.template_env = jinja2.Environment(loader=template_loader)
        self.template = self.template_env.get_template("hanwha_securities_template.md")
    
    def generate_report(
        self,
        company_name: str,
        bull_argument: str,
        bear_argument: str,
        synthesis: str,
        analysis_data: Dict,
        graph_paths: Optional[list] = None,
        sources: Optional[list] = None
    ) -> str:
        """
        한화투자증권 스타일 마크다운 리포트 생성
        
        Args:
            company_name: 기업명
            bull_argument: Bull 에이전트 주장
            bear_argument: Bear 에이전트 주장
            synthesis: Synthesizer 최종 판단
            analysis_data: 재무/비재무 분석 데이터
            graph_paths: Graph 경로 (Provenance)
            sources: 참고 자료 링크
        
        Returns:
            Markdown 형식 리포트
        """
        # Synthesis에서 투자의견 및 목표주가 추출
        investment_opinion = self._extract_opinion(synthesis)
        target_price = self._extract_target_price(synthesis)
        confidence = self._extract_confidence(synthesis)
        
        # 템플릿 렌더링
        report_md = self.template.render(
            company_name=company_name,
            date=datetime.now().strftime("%Y.%m.%d"),
            target_price=f"{target_price:,}",
            upside=self._calculate_upside(target_price, analysis_data.get('current_price')),
            investment_opinion=investment_opinion,
            executive_summary=self._generate_summary(analysis_data, synthesis),
            
            # 재무 데이터
            revenue_2023=f"{analysis_data.get('revenue_2023', 0):,}억원",
            revenue_2024=f"{analysis_data.get('revenue_2024', 0):,}억원",
            revenue_2025=f"{analysis_data.get('revenue_2025', 0):,}억원",
            op_2023=f"{analysis_data.get('op_2023', 0):,}억원",
            op_2024=f"{analysis_data.get('op_2024', 0):,}억원",
            op_2025=f"{analysis_data.get('op_2025', 0):,}억원",
            eps_2023=f"{analysis_data.get('eps_2023', 0):,}원",
            eps_2024=f"{analysis_data.get('eps_2024', 0):,}원",
            eps_2025=f"{analysis_data.get('eps_2025', 0):,}원",
            
            # 분석 섹션
            business_structure=analysis_data.get('business_structure', ''),
            key_products=analysis_data.get('key_products', ''),
            financial_performance=analysis_data.get('financial_performance', ''),
            valuation=analysis_data.get('valuation', ''),
            
            # 변증법 토론 결과
            bull_argument=bull_argument,
            bear_argument=bear_argument,
            synthesis=synthesis,
            confidence=f"{confidence:.1%}",
            
            # Provenance
            graph_paths=self._format_graph_paths(graph_paths) if graph_paths else "N/A",
            sources=self._format_sources(sources) if sources else "N/A"
        )
        
        return report_md
    
    def _extract_opinion(self, synthesis: str) -> str:
        """Synthesis에서 투자의견 추출 (Buy/Hold/Sell)"""
        # LLM 파싱 또는 키워드 기반 추출
        if "매수" in synthesis or "Buy" in synthesis:
            return "매수 (Buy)"
        elif "매도" in synthesis or "Sell" in synthesis:
            return "매도 (Sell)"
        else:
            return "중립 (Hold)"
    
    def _extract_target_price(self, synthesis: str) -> int:
        """Synthesis에서 목표주가 추출"""
        import re
        # 정규식으로 "목표주가: 85,000원" 패턴 찾기
        match = re.search(r'목표주가[:\s]*([0-9,]+)원', synthesis)
        if match:
            return int(match.group(1).replace(',', ''))
        return 0
    
    def _extract_confidence(self, synthesis: str) -> float:
        """Synthesis에서 신뢰도 추출"""
        import re
        match = re.search(r'신뢰도[:\s]*([0-9.]+)', synthesis)
        if match:
            return float(match.group(1))
        return 0.7  # 기본값
    
    def _calculate_upside(self, target_price: int, current_price: Optional[int]) -> str:
        """예상 수익률 계산"""
        if not current_price or current_price == 0:
            return "N/A"
        upside = ((target_price - current_price) / current_price) * 100
        return f"{upside:+.1f}"
    
    def _generate_summary(self, analysis_data: Dict, synthesis: str) -> str:
        """Investment Summary 생성"""
        # 최대 3줄 요약
        summary_lines = synthesis.split('\n')[:3]
        return '\n'.join(summary_lines)
    
    def _format_graph_paths(self, paths: list) -> str:
        """Graph Path를 텍스트로 포맷팅"""
        formatted = []
        for i, path in enumerate(paths, 1):
            path_str = " → ".join([
                f"**{node['name']}**" if 'name' in node else f"*{node['type']}*"
                for node in path
            ])
            formatted.append(f"{i}. {path_str}")
        return '\n'.join(formatted)
    
    def _format_sources(self, sources: list) -> str:
        """출처 포맷팅"""
        formatted = []
        for source in sources:
            formatted.append(f"- {source['title']} (페이지 {source.get('page', 'N/A')})")
```

### 캐시 무효화 전략

현재 시스템(v0.1.0)은 캐시 무효화 전략이 없어 그래프 업데이트 후에도 오래된 캐시를 사용합니다.

#### 해결 방안

```python
# src/pipeline/nodes.py

import hashlib
from datetime import datetime
from typing import Dict, Optional

class GraphRAGCache:
    """캐시 관리 클래스"""
    
    def __init__(self, max_size: int = 100):
        self._cache: Dict[str, Dict] = {}
        self._timestamps: Dict[str, datetime] = {}
        self._graph_version: int = 0  # 그래프 버전 추적
        self.max_size = max_size
    
    def get(self, cache_key: str, graph_version: int) -> Optional[Dict]:
        """
        캐시 조회 (그래프 버전 확인)
        
        Args:
            cache_key: 캐시 키
            graph_version: 현재 그래프 버전
        
        Returns:
            캐시된 결과 (버전 불일치 시 None)
        """
        if cache_key not in self._cache:
            return None
        
        # 그래프가 업데이트되었으면 캐시 무효화
        cached_version = self._cache[cache_key].get('_version', 0)
        if cached_version < graph_version:
            logger.info(f"Cache invalidated: {cache_key} (version {cached_version} < {graph_version})")
            del self._cache[cache_key]
            del self._timestamps[cache_key]
            return None
        
        return self._cache[cache_key]['data']
    
    def set(self, cache_key: str, data: Dict, graph_version: int):
        """
        캐시 저장 (그래프 버전 포함)
        """
        # 캐시 크기 제한
        if len(self._cache) >= self.max_size:
            # LRU: 가장 오래된 항목 제거
            oldest_key = min(self._timestamps, key=self._timestamps.get)
            del self._cache[oldest_key]
            del self._timestamps[oldest_key]
        
        self._cache[cache_key] = {
            'data': data,
            '_version': graph_version,
            '_timestamp': datetime.now()
        }
        self._timestamps[cache_key] = datetime.now()
    
    def invalidate_all(self):
        """그래프 업데이트 시 호출: 버전 증가"""
        self._graph_version += 1
        logger.info(f"Graph updated: version {self._graph_version}")
    
    def get_graph_version(self) -> int:
        return self._graph_version

# 전역 캐시 인스턴스
_graphrag_cache = GraphRAGCache(max_size=100)
```

### Circuit Breaker 패턴

```python
# src/utils/circuit_breaker.py

from enum import Enum
from datetime import datetime, timedelta

class CircuitState(Enum):
    CLOSED = "closed"  # 정상
    OPEN = "open"      # 차단 (에러 임계값 초과)
    HALF_OPEN = "half_open"  # 복구 시도

class CircuitBreaker:
    """외부 서비스(Neo4j, LLM) 호출 보호"""
    
    def __init__(self, failure_threshold: int = 5, timeout: int = 60):
        self.failure_threshold = failure_threshold
        self.timeout = timeout  # 초 단위
        self.failure_count = 0
        self.last_failure_time: Optional[datetime] = None
        self.state = CircuitState.CLOSED
    
    def call(self, func, *args, **kwargs):
        """함수 호출 (Circuit Breaker 적용)"""
        
        if self.state == CircuitState.OPEN:
            # 타임아웃 경과 시 HALF_OPEN으로 전환
            if datetime.now() - self.last_failure_time > timedelta(seconds=self.timeout):
                self.state = CircuitState.HALF_OPEN
                logger.info("Circuit breaker: OPEN → HALF_OPEN")
            else:
                raise Exception("Circuit breaker is OPEN")
        
        try:
            result = func(*args, **kwargs)
            
            # 성공 시 카운터 리셋
            if self.state == CircuitState.HALF_OPEN:
                self.state = CircuitState.CLOSED
                logger.info("Circuit breaker: HALF_OPEN → CLOSED")
            
            self.failure_count = 0
            return result
        
        except Exception as e:
            self.failure_count += 1
            self.last_failure_time = datetime.now()
            
            if self.failure_count >= self.failure_threshold:
                self.state = CircuitState.OPEN
                logger.error(f"Circuit breaker: OPEN (failures: {self.failure_count})")
            
            raise e

# 전역 인스턴스
_neo4j_circuit = CircuitBreaker(failure_threshold=5, timeout=60)
_llm_circuit = CircuitBreaker(failure_threshold=3, timeout=30)
```

## Phase 4: 웹 애플리케이션 및 RAG 인터페이스

> **우선순위**: 🟡 Normal (Phase 3 이후)
> **목표**: 일반 사용자도 쉽게 사용할 수 있는 웹 인터페이스 및 대화형 RAG 시스템 구축

### 4.1 FastAPI 백엔드 구축

**목적**: 에이전트 오케스트레이션 및 데이터 관리 API 제공

**주요 기능**:
- **Agent Orchestration API**: `POST /run-analysis` (리포트 생성 트리거)
- **Document Management API**: `POST /upload` (PDF/CSV 업로드 및 자동 파싱)
- **RAG Chat API**: `POST /chat` (KG 기반 질의응답)
- **Stream Response**: SSE(Server-Sent Events)를 이용한 실시간 에이전트 생각(Thought) 스트리밍

**아키텍처**:
```
[Frontend] <--> [FastAPI] <--> [Orchestrator] <--> [Agents/KG]
```

### 4.2 프론트엔드 대시보드 (React/Next.js)

**목적**: 직관적인 시각화 및 제어 대시보드

**주요 화면**:
1. **Dashboard**: 전체 분석 현황, 최근 리포트 요약, 주요 시장 지표(Macro/Price) 위젯.
2. **File Manager**: 원본 문서(PDF, CSV) 업로드 및 파싱 상태 모니터링.
3. **Report Viewer**: 생성된 구조화 리포트(Markdown/HTML) 뷰어, 차트 시각화 포함.
4. **Graph Explorer**: PyVis/D3.js 기반 Knowledge Graph 인터랙티브 탐색.
5. **Chat Interface**: 
   - 리포트 기반 심층 질의 (Context-aware Chat).
   - "왜 이 주식이 유망해?" 등의 질문에 근거(Graph path)와 함께 답변.

### 4.3 RAG 기반 대화형 인터페이스

**목적**: 생성된 리포트와 KG를 바탕으로 한 근거 있는 답변 제공

**기능**:
- **Context Injection**: 현재 보고 있는 리포트와 관련된 Sub-Graph를 LLM 컨텍스트에 주입.
- **Citation**: 답변 생성 시 참조한 문서(PDF 페이지)나 데이터(CSV 행) 링크 제공.
- **Follow-up Suggestions**: 사용자가 다음에 물어볼 만한 질문 추천.

### 4.4 구현 파일 (예정)

- `src/api/main.py`: FastAPI 엔트리 포인트
- `src/api/routes/`: 라우터 분리 (agent, content, chat)
- `frontend/`: Next.js 프로젝트 디렉토리
