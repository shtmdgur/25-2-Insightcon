## 🏗 1. Global State Architecture

LangGraph의 `TypedDict`를 활용하여 전역 상태(Global State)를 엄격하게 관리합니다.

### 1.1 Core State Class

```python
# src/pipeline/schema.py

from typing import TypedDict, List, Dict, Optional, Annotated, Literal
import operator

class ReportState(TypedDict):
    """
    워크플로우 전체에서 공유되는 중앙 상태 객체
    """
    # ----------------------------------------------------
    # 1. Inputs (사용자 입력)
    # ----------------------------------------------------
    query: str                              # 사용자 질문
    target_companies: List[str]             # 분석 대상 기업 (예: ["삼성전자", "SK하이닉스"])
    report_type: Literal["scan", "deep"]    # 분석 깊이 ("scan": Quick, "deep": Deep)
    document_path: Optional[str]            # (Optional) 분석할 PDF/문서 경로

    # ----------------------------------------------------
    # 2. Graph Data (Knowledge Graph)
    # ----------------------------------------------------
    kg_updates: Annotated[List[Dict], operator.add] # 새로 생성된 노드/엣지 (Reducer: append)
    schema_errors: List[str]                        # Quality Check에서 발견된 에러
    
    # ----------------------------------------------------
    # 3. Retrieval Results (RAG)
    # ----------------------------------------------------
    graph_rag_results: Dict[str, Any]       # Neo4j 검색 결과 (Entities, Relations, Paths)
    news_events: List[Dict]                 # 관련 뉴스 이벤트 (검색된 것)
    
    # ----------------------------------------------------
    # 4. Analysis & Debate (Multi-Agent State)
    # ----------------------------------------------------
    # Analyst Agents Output
    fundamental_analysis: Optional[str]     # 재무 분석 결과
    trend_analysis: Optional[str]           # 트렌드(SAX) 분석 결과
    event_analysis: Optional[str]           # 이벤트 임팩트 분석 결과
    
    # Debate State
    bull_argument: Optional[str]            # Bull 에이전트 논리
    bear_argument: Optional[str]            # Bear 에이전트 논리
    debate_turn_count: int = 0              # 토론 라운드 카운트 (Max 3)
    synthesis_verdict: Optional[str]        # Synthesizer 종합 판단
    
    # ----------------------------------------------------
    # 5. Metadata & Provenance
    # ----------------------------------------------------
    retry_count: int                        # 재시도 횟수 (Infinite Loop 방지)
    execution_trace: Annotated[List[str], operator.add] # 실행 로그
    critical_paths: List[str]               # 근거로 사용된 핵심 경로 (Provenance)
    final_report: Optional[str]             # 최종 생성된 마크다운 리포트
```

### 1.2 Data Models (Pydantic)

데이터의 일관성을 위해 Pydantic 모델을 사용하여 I/O를 검증합니다.

```python
# src/models/nodes.py

from pydantic import BaseModel, Field
from enum import Enum

class NodeType(str, Enum):
    COMPANY = "Company"
    PRODUCT = "Product"
    EVENT = "Event"
    METRIC = "Metric"
    TREND = "Trend"

class Entity(BaseModel):
    name: str
    type: NodeType
    properties: Dict[str, Any] = Field(default_factory=dict)

class RelationType(str, Enum):
    COMPETITOR_OF = "COMPETITOR_OF"
    SUPPLIER_OF = "SUPPLIER_OF"
    AFFECTS = "AFFECTS"
    HAS_METRIC = "HAS_METRIC"

class Triplet(BaseModel):
    subject: str
    predicate: RelationType
    object: str
    weight: float = 1.0
```

## 🧩 2. Node Interface Specification

각 노드(Node)의 입력과 출력을 명확히 정의하여 의존성을 관리합니다.

### 2.1 Data Ingestion Nodes

#### `Node: PDFParser` (Phase 0.3)
- **Role**: PDF를 텍스트 및 차트 데이터로 변환 (Gemini Files API 활용)
- **Strategy**: **Media-First** (이미지 우선 배치)
- **Input**: `state.document_path`
- **Output**: 
    - `parsed_text`: str
    - `file_uri`: str (Gemini Files API 업로드 URI)
    - `extracted_charts`: List[Dict] (VLM 분석 결과)
- **Function Signature**:
    ```python
    def pdf_parser_node(state: ReportState) -> Dict:
        # 1. client.files.upload(path)
        # 2. client.models.generate_content([file_uri, prompt])
        return {"parsed_text": ..., "file_uri": ...}
    ```

#### `Node: KGConstruction` (Phase 1.1)
- **Role**: 텍스트/차트 데이터에서 Entity/Relation 추출
- **Configuration**: Seed Ontology 사용
- **Optimization**: **Batch API** (비용 절감)
- **Input**: `parsed_text`, `file_uri`
- **Output**: 
    - `kg_updates`: List[Triplet]
    - `batch_job_id`: str (비동기 작업 ID)
- **State Logic**:
    - Batch Job 실행 -> `batch_job_id` 저장 -> Workflow 일시 중지 or Polling Node로 전환
    - 완료 시 결과 수신하여 `kg_updates` 반영

### 2.2 Analysis Nodes (Phase 2.4 - Analyst Team)

이 노드들은 병렬로 실행됩니다 (`Map-Reduce` 패턴).

#### `Node: FundamentalsAnalyst`
- **Role**: 재무 데이터 분석 (매출, 영업이익, 부채 등)
- **Model**: **Quick** (Gemini 2.5 Flash)
- **Input**: `state.graph_rag_results` (Metric 노드 위주)
- **Output**: `state.fundamental_analysis`
- **Prompt Input**:
    ```json
    {
      "metrics": ["Revenue 2024: 100B", "Profit Margin: 15%"],
      "comparison": "YoY +10%"
    }
    ```

#### `Node: TrendAnalyst`
- **Role**: 시계열 패턴(SAX) 및 수급 분석
- **Model**: **Quick** (Gemini 2.5 Flash)
- **Input**: `state.graph_rag_results` (Trend 노드 위주)
- **Output**: `state.trend_analysis`

#### `Node: EventAnalyst`
- **Role**: 뉴스/이벤트의 임팩트 분석
- **Model**: **Deep** (Gemini 3 Pro)
- **Input**: `state.news_events`, `state.graph_rag_results` (Event 노드)
- **Output**: `state.event_analysis`

### 2.3 Debate & Synthesis Nodes (Phase 2.3)

#### `Node: BullAgent`
- **Role**: 긍정적 요소(기회) 강조 및 논리 전개
- **Model**: **Quick** (Gemini 2.5 Flash)
- **Input**: 
    - `fundamental_analysis`
    - `trend_analysis`
    - `event_analysis`
- **Output**: `state.bull_argument`

#### `Node: BearAgent`
- **Role**: 부정적 요소(리스크) 강조 및 방어 논리
- **Model**: **Quick** (Gemini 2.5 Flash)
- **Input**: (Bull과 동일)
- **Output**: `state.bear_argument`

#### `Node: Synthesizer`
- **Role**: Bull/Bear 주장을 변증법적으로 통합하고 최종 판단
- **Model**: **Deep** (Gemini 3 Pro)
- **Input**: `bull_argument`, `bear_argument`, `critical_paths`
- **Output**: `state.synthesis_verdict`

## 🔄 4. State Transition & Routing Logic

### 4.1 Conditional Edges

1. **Parser Fallback**: 실패 시 대체 파서로 재시도
2. **Quality Check Loop**:
    ```python
    def route_after_qc(state):
        if state['schema_errors'] and state['retry_count'] < MAX_RETRIES:
            return "retry_kg_construction"
        return "graph_rag_query"
    ```
3. **Analyst Parallelism**:
    - Query 질의 시 -> `[Fundamentals, Trend, Event]` 병렬 실행 -> `Debate`

4. **Debate Loop Control**:
    ```python
    def route_debate(state):
        # Bull -> Bear -> (Check) -> Bull ...
        if state['debate_turn_count'] < 3:
            return "bull" # Continue Debate
        return "synthesizer" # End Debate
    ```
