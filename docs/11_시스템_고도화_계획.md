## 개요 및 목표

### 현재 시스템 한계

현재 시스템(v0.1.0)은 기본적인 멀티 에이전트 워크플로우를 갖추고 있으나, 다음과 같은 한계가 있습니다:

1. **데이터 처리**: PDF 이미지/차트 정보 손실, CSV 데이터 비효율적 처리
2. **엔티티 정규화**: 동일 기업의 다양한 표기(삼성/삼성전자/Samsung) 미통합
3. **관계 추출**: 단순한 관계 매핑 (모든 제품을 모든 기업에 연결)
4. **시계열 통합**: 동적 데이터(뉴스, 이벤트, 주가 패턴) 미반영
5. **검색 품질**: 단순 Cypher 쿼리, Multi-hop Traversal 부재
6. **추론 고도화**: 단일 관점 분석, 변증법적 토론 부재
7. **설명 가능성**: 근거 추적 미흡, 시각화 부재

### 고도화 목표

**금융 특화 Knowledge Graph RAG** 시스템을 구축하여:

- 정적 데이터(리포트, 재무제표)와 동적 데이터(뉴스, 시계열)를 통합
- Seed 온톨로지 기반 정확한 엔티티/관계 추출
- Multi-hop 검색 및 변증법적 에이전트 토론을 통한 심층 분석
- 투명한 근거 제시 및 시각적 설명 가능성 확보

### 0.1 PDF 이미지/차트 처리

#### 문제점
pymupdf4llm으로 PDF를 파싱하면 이미지는 추출되지만, 차트의 의미(트렌드, 수치)는 유실됩니다.

#### 해결 방안

```python
# src/utils/pdf_processor.py

import pymupdf4llm
from langchain_openai import ChatOpenAI
import base64

class FinancialPDFProcessor:
    def __init__(self, llm: ChatOpenAI):
        self.llm = llm  # GPT-4o 또는 Claude 3.5 Sonnet (Vision 필수)
    
    def process_pdf_with_images(self, pdf_path: str) -> dict:
        """
        PDF를 파싱하고 이미지는 VLM으로 분석
        
        Returns:
            {
                "text": "Markdown 텍스트",
                "images": [
                    {
                        "path": "image_1.png",
                        "description": "VLM이 생성한 차트 설명",
                        "page": 5
                    }
                ]
            }
        """
        # 1. pymupdf4llm으로 텍스트 + 이미지 추출
        md_text = pymupdf4llm.to_markdown(pdf_path, write_images=True)
        
        # 2. 추출된 이미지 경로 파싱
        images = self._extract_image_paths(md_text)
        
        # 3. 각 이미지를 VLM으로 분석
        enriched_images = []
        for img_path in images:
            description = self._analyze_chart_with_vlm(img_path)
            enriched_images.append({
                "path": img_path,
                "description": description,
                "page": self._get_page_number(img_path)
            })
        
        # 4. 원본 Markdown에 차트 설명 삽입
        enriched_md = self._insert_descriptions(md_text, enriched_images)
        
        return {
            "text": enriched_md,
            "images": enriched_images
        }
    
    def _analyze_chart_with_vlm(self, image_path: str) -> str:
        """
        VLM을 사용하여 차트/도표 분석
        """
        # 이미지를 base64로 인코딩
        with open(image_path, "rb") as f:
            image_base64 = base64.b64encode(f.read()).decode()
        
        prompt = """
        이 이미지는 금융 리포트의 차트 또는 도표입니다.
        
        다음 정보를 추출하세요:
        1. 차트 유형 (막대그래프, 라인차트, 파이차트 등)
        2. 주요 데이터 포인트 및 수치
        3. 트렌드 요약 (상승/하락/변동 없음)
        4. 핵심 인사이트
        
        텍스트 형식으로 요약하세요.
        """
        
        # GPT-4V 또는 Claude 3.5 호출
        response = self.llm.invoke([
            {"type": "text", "text": prompt},
            {"type": "image_url", "image_url": f"data:image/png;base64,{image_base64}"}
        ])
        
        return response.content
```

**장점**:
- 차트의 인사이트가 텍스트화되어 KG 구축 시 활용 가능
- LLM이 차트 데이터를 기반으로 추론 가능

**구현 우선순위**: 1순위 (데이터 수집의 기초)

### 0.2 CSV 데이터 효율적 처리

#### 문제점

**전략**: CSV는 Neo4j **노드 속성(Property)**로 직접 매핑

```python
# src/crawl/csv_loader.py

import pandas as pd
from typing import Dict, List

class FinancialCSVLoader:
    def __init__(self, neo4j_client):
        self.neo4j = neo4j_client
    
    def load_financial_csv(self, csv_path: str, company_name: str):
        """
        재무 CSV를 Neo4j 속성으로 저장
        
        CSV 예시:
        date,revenue,profit,debt
        2024-Q1,100000,10000,5000
        2024-Q2,110000,12000,4800
        """
        df = pd.read_csv(csv_path)
        
        for _, row in df.iterrows():
            period = row['date']
            
            # Financial 노드 생성 (분기별)
            self.neo4j.run("""
                MATCH (c:Company {name: $company_name})
                MERGE (f:Financial {
                    period: $period,
                    company: $company_name
                })
                SET f.revenue = $revenue,
                    f.profit = $profit,
                    f.debt = $debt
                MERGE (c)-[:HAS_FINANCIAL]->(f)
            """, {
                "company_name": company_name,
                "period": period,
                "revenue": float(row['revenue']),
                "profit": float(row['profit']),
                "debt": float(row['debt'])
            })
    
    def query_financial_data(self, company_name: str, metric: str):
        """
        에이전트가 특정 지표를 조회할 때 사용
        """
        result = self.neo4j.query("""
            MATCH (c:Company {name: $company_name})-[:HAS_FINANCIAL]->(f:Financial)
            RETURN f.period AS period, f[$metric] AS value
            ORDER BY f.period
        """, {"company_name": company_name, "metric": metric})
        
        return result
```

### 1.2 엔티티 연결 및 정규화 (Entity Linking)

#### 문제점
"삼성", "삼성전자", "Samsung Elec", "005930" → 모두 다른 노드로 생성됨

#### 해결 방안

**Master Data 구축**

```python
# src/utils/entity_normalizer.py

import pandas as pd
from neo4j import GraphDatabase

class EntityNormalizer:
    def __init__(self, neo4j_client):
        self.neo4j = neo4j_client
        self.master_data = self._load_master_data()
    
    def _load_master_data(self) -> pd.DataFrame:
        """
        KRX 상장사 리스트 로드
        
        CSV 예시:
        ticker,name,name_en,aliases
        005930,삼성전자,Samsung Electronics,"삼성,Samsung,SEC"
        000660,SK하이닉스,SK Hynix,"하이닉스,Hynix"
        """
        return pd.read_csv("data/master/krx_companies.csv")
    
    def normalize_entity(self, mention: str) -> dict:
        """
        텍스트 멘션을 표준 엔티티로 매핑
        
        Returns:
            {
                "canonical_name": "삼성전자",
                "ticker": "005930",
                "aliases": ["삼성", "Samsung"],
                "confidence": 0.95
            }
        """
        # 1. Exact Match (Ticker 또는 정확한 이름)
        exact_match = self.master_data[
            (self.master_data['ticker'] == mention) |
            (self.master_data['name'] == mention) |
            (self.master_data['name_en'] == mention)
        ]
        
        if not exact_match.empty:
            return self._to_entity_dict(exact_match.iloc[0], confidence=1.0)
        
        # 2. Fuzzy Matching (철자 유사도)
        fuzzy_matches = self._fuzzy_search(mention)
        if fuzzy_matches:
            return fuzzy_matches[0]  # 가장 유사도 높은 것
        
        # 3. Vector Similarity (의미 유사도)
        semantic_match = self._semantic_search(mention)
        return semantic_match
    
    def _fuzzy_search(self, mention: str) -> List[dict]:
        """Levenshtein Distance 기반 유사도"""
        from fuzzywuzzy import fuzz
        
        matches = []
        for _, row in self.master_data.iterrows():
            score = max(
                fuzz.ratio(mention, row['name']),
                fuzz.ratio(mention, row['name_en'])
            )
            if score > 80:  # 임계값
                matches.append(self._to_entity_dict(row, confidence=score/100))
        
        return sorted(matches, key=lambda x: x['confidence'], reverse=True)
    
    def _semantic_search(self, mention: str) -> dict:
        """Embedding 기반 의미 유사도"""
        # OpenAI Embeddings 또는 한국어 SBERT 사용
        from langchain_openai import OpenAIEmbeddings
        
        embeddings = OpenAIEmbeddings()
        mention_vec = embeddings.embed_query(mention)
        
        # 미리 계산된 Master Data Embedding과 비교
        # (사전에 prepare_embeddings()로 계산)
        similarities = self._cosine_similarity(mention_vec, self.master_embeddings)
        
        best_idx = np.argmax(similarities)
        return self._to_entity_dict(
            self.master_data.iloc[best_idx],
            confidence=similarities[best_idx]
        )
```

```python
from saxpy.sax import sax_via_window

class TimeSeriesProcessor:
    def __init__(self, neo4j_client):
        self.neo4j = neo4j_client
    
    def process_stock_price(self, company_ticker: str, prices: List[float]):
        """
        주가 시계열을 SAX로 변환하여 저장
        
        예: [100, 105, 110, 108, 115] → "abcde" (상승 패턴)
        """
        sax_string = sax_via_window(
            ts=prices,
            win_size=5,
            paa_size=3,
            alphabet_size=5,
            nr_strategy='normal'
        )
        
        # Trend 노드 생성
        self.neo4j.run("""
            MATCH (c:Company {ticker: $ticker})
            MERGE (t:Trend {
                period: $period,
                pattern: $sax_string,
                type: $trend_type
            })
            MERGE (c)-[:HAS_TREND]->(t)
        """, {
            "ticker": company_ticker,
            "period": "2024-Q4",
            "sax_string": sax_string,
            "trend_type": self._classify_trend(sax_string)  # "Upward", "Downward", "Volatile"
        })
```

```python
    def extract_events_from_news(self, news_text: str, date: str):

        뉴스에서 이벤트 추출
```

**Time-decay 함수**:

```python
def calculate_time_decay(event_date: datetime, current_date: datetime) -> float:
    """
    최근 이벤트일수록 가중치 ↑
    
    예: 1개월 전 = 0.9, 6개월 전 = 0.5, 1년 전 = 0.2
    """
    days_diff = (current_date - event_date).days
    decay_factor = np.exp(-days_diff / 90)  # 90일 반감기
    return max(decay_factor, 0.1)  # 최소 0.1
```

```python
# src/agents/quality_check.py

class QualityCheckAgent:
    def verify_extraction(self, source_text: str, extracted_triplet: dict) -> bool:
        """
        추출된 Triplet이 원문과 일치하는지 검증
        
        Args:
            source_text: 원본 문서 청크
            extracted_triplet: {"subject": "삼성전자", "predicate": "MANUFACTURES", "object": "HBM3"}
        
        Returns:
            True if verified, False otherwise
        """
        prompt = f"""
        원문: {source_text}
        
        추출된 정보: {extracted_triplet}
        
        질문: 위 정보가 원문에서 정확히 추출되었습니까?
        - 주어, 동사, 목적어가 모두 원문에 존재합니까?
        - 관계가 명시적으로 서술되어 있습니까?
        
        답변: Yes/No (근거 포함)
        """
        
        response = self.llm.invoke(prompt)
        
        if "No" in response.content:
            logger.warning(f"Extraction failed verification: {extracted_triplet}")
            return False
        
        return True
```

#### Relevance Scoring at Retrieval

```python
def score_subgraph_relevance(self, query: str, subgraph: dict) -> float:
    """
    검색된 서브그래프가 질문에 적합한지 점수화
    
    Args:
        query: 사용자 질의
        subgraph: Neo4j에서 검색된 서브그래프 (nodes, edges)
    
    Returns:
        Relevance score (0.0 ~ 1.0)
    """
    subgraph_summary = self._summarize_subgraph(subgraph)
    
    prompt = f"""
    질문: {query}
    검색된 정보: {subgraph_summary}
    
    이 정보가 질문에 답하기에 충분합니까?
    점수 (0.0 ~ 1.0):
    """
    
    response = self.llm.invoke(prompt)
    score = float(response.content.strip())
    
    if score < 0.6:
        logger.info("Low relevance, triggering query rewrite")
        # Query Rewrite 트리거
    
    return score
```

### 2.2 Multi-hop Retrieval

#### Graph Traversal 전략

```python
# src/pipeline/graphrag_query.py

class MultiHopGraphRAG:
    def __init__(self, neo4j_client, llm):
        self.neo4j = neo4j_client
        self.llm = llm
    
    def multi_hop_search(self, query: str, max_hops: int = 2):
        """
        단계적 그래프 탐색
        
        예: "SK하이닉스의 주요 경쟁사와 그들의 최근 이슈는?"
        - Hop 1: SK하이닉스 → COMPETITOR_OF → 삼성전자
        - Hop 2: 삼성전자 → AFFECTED_BY → Event (HBM3 양산)
        """
        # 1. Anchor Entity 식별
        anchor_entities = self._extract_entities_from_query(query)
        
        # 2. 1-Hop 확장
        hop1_results = self._expand_1hop(anchor_entities, query)
        
        # 3. Path Filtering (불필요한 관계 제거)
        filtered_paths = self._filter_irrelevant_paths(hop1_results, query)
        
        # 4. 2-Hop 확장 (필요 시)
        if self._needs_further_expansion(filtered_paths, query):
            hop2_results = self._expand_2hop(filtered_paths, query)
            return hop2_results
        
        return filtered_paths
    
    def _expand_1hop(self, anchor_entities: List[str], query: str):
        """
        1-Hop 확장 (직접 연결된 노드)
        """
        cypher = """
        UNWIND $anchors AS anchor_name
        MATCH (anchor {name: anchor_name})-[r]-(neighbor)
        RETURN anchor, type(r) AS rel_type, neighbor
        """
        
        results = self.neo4j.query(cypher, {"anchors": anchor_entities})
        return results
    
    def _filter_irrelevant_paths(self, paths: List, query: str):
        """
        LLM으로 관련 없는 경로 제거
        """
        filtered = []
        for path in paths:
            if self._is_relevant_path(path, query):
                filtered.append(path)
        
        return filtered
    
    def _is_relevant_path(self, path: dict, query: str) -> bool:
        """
        경로 relevance 판단
        """
        prompt = f"""
        질문: {query}
        경로: {path['anchor']['name']} -[{path['rel_type']}]-> {path['neighbor']['name']}
        
        이 경로가 질문과 관련 있습니까? Yes/No
        """
        
        response = self.llm.invoke(prompt)
        return "Yes" in response.content
```

```python
    def generate_report_with_provenance(self, analysis: str, graph_paths: List):

        {self._format_sources(graph_paths)}
        """

    def _format_graph_path(self, paths: List) -> str:
        """
        Graph Path를 가독성 높게 표현
        
        예: [삼성전자] -[COMPETITOR_OF]-> [SK하이닉스] -[AFFECTED_BY]-> [HBM3 양산]

            path_str = " -> ".join([
                f"[{node['name']}]" if i % 2 == 0 else f"-[{node['type']}]-"
                for i, node in enumerate(path)
            ])
            formatted.append(path_str)
        
        return "\n".join(formatted)
    
    def _format_sources(self, paths: List) -> str:
        """
        원문 링크 제공
        
        예: KB증권 리포트 5페이지, 매일경제 2024-12-01
        """
        sources = []
        for path in paths:
            for node in path:
                if 'source_doc' in node:
                    sources.append(f"- {node['source_doc']} (페이지 {node.get('page', 'N/A')})")
        
        return "\n".join(set(sources))  # 중복 제거
```

> **목표**: GraphRAG 캐시 무효화 및 성능 최적화

### 캐시 무효화 전략

현재 시스템(v0.1.0)은 캐시 무효화 전략이 없어 그래프 업데이트 후에도 오래된 캐시를 사용합니다.

#### 해결 방안

```python
# src/pipeline/nodes.py

import hashlib
from datetime import datetime
from typing import Dict, Optional

class GraphRAGCache:
    """캐시 관리 클래스"""
    
    def __init__(self, max_size: int = 100):
        self._cache: Dict[str, Dict] = {}
        self._timestamps: Dict[str, datetime] = {}
        self._graph_version: int = 0  # 그래프 버전 추적
        self.max_size = max_size
    
    def get(self, cache_key: str, graph_version: int) -> Optional[Dict]:
        """
        캐시 조회 (그래프 버전 확인)
        
        Args:
            cache_key: 캐시 키
            graph_version: 현재 그래프 버전
        
        Returns:
            캐시된 결과 (버전 불일치 시 None)
        """
        if cache_key not in self._cache:
            return None
        
        # 그래프가 업데이트되었으면 캐시 무효화
        cached_version = self._cache[cache_key].get('_version', 0)
        if cached_version < graph_version:
            logger.info(f"Cache invalidated: {cache_key} (version {cached_version} < {graph_version})")
            del self._cache[cache_key]
            del self._timestamps[cache_key]
            return None
        
        return self._cache[cache_key]['data']
    
    def set(self, cache_key: str, data: Dict, graph_version: int):
        """
        캐시 저장 (그래프 버전 포함)
        """
        # 캐시 크기 제한
        if len(self._cache) >= self.max_size:
            # LRU: 가장 오래된 항목 제거
            oldest_key = min(self._timestamps, key=self._timestamps.get)
            del self._cache[oldest_key]
            del self._timestamps[oldest_key]
        
        self._cache[cache_key] = {
            'data': data,
            '_version': graph_version,
            '_timestamp': datetime.now()
        }
        self._timestamps[cache_key] = datetime.now()
    
    def invalidate_all(self):
        """그래프 업데이트 시 호출: 버전 증가"""
        self._graph_version += 1
        logger.info(f"Graph updated: version {self._graph_version}")
    
    def get_graph_version(self) -> int:
        return self._graph_version

# 전역 캐시 인스턴스
_graphrag_cache = GraphRAGCache(max_size=100)
```

```python
# src/utils/retry_handler.py

from tenacity import retry, stop_after_attempt, wait_exponential, retry_if_exception_type
import logging

logger = logging.getLogger(__name__)

def retry_on_llm_error(func):
    """LLM 호출 실패 시 재시도"""
    return retry(
        stop=stop_after_attempt(3),  # 최대 3회 재시도
        wait=wait_exponential(multiplier=1, min=2, max=10),  # 지수 백오프
        retry=retry_if_exception_type((TimeoutError, ConnectionError)),
        before_sleep=lambda retry_state: logger.warning(
            f"Retrying {func.__name__} (attempt {retry_state.attempt_number})"
        )
    )(func)

# 사용 예시
@retry_on_llm_error
def call_llm_with_retry(llm, prompt):
    """LLM 호출 (자동 재시도)"""
    response = llm.invoke(prompt)
    return response.content
```

### Circuit Breaker 패턴

```python
# src/utils/circuit_breaker.py

from enum import Enum
from datetime import datetime, timedelta

class CircuitState(Enum):
    CLOSED = "closed"  # 정상
    OPEN = "open"      # 차단 (에러 임계값 초과)
    HALF_OPEN = "half_open"  # 복구 시도

class CircuitBreaker:
    """외부 서비스(Neo4j, LLM) 호출 보호"""
    
    def __init__(self, failure_threshold: int = 5, timeout: int = 60):
        self.failure_threshold = failure_threshold
        self.timeout = timeout  # 초 단위
        self.failure_count = 0
        self.last_failure_time: Optional[datetime] = None
        self.state = CircuitState.CLOSED
    
    def call(self, func, *args, **kwargs):
        """함수 호출 (Circuit Breaker 적용)"""
        
        if self.state == CircuitState.OPEN:
            # 타임아웃 경과 시 HALF_OPEN으로 전환
            if datetime.now() - self.last_failure_time > timedelta(seconds=self.timeout):
                self.state = CircuitState.HALF_OPEN
                logger.info("Circuit breaker: OPEN → HALF_OPEN")
            else:
                raise Exception("Circuit breaker is OPEN")
        
        try:
            result = func(*args, **kwargs)
            
            # 성공 시 카운터 리셋
            if self.state == CircuitState.HALF_OPEN:
                self.state = CircuitState.CLOSED
                logger.info("Circuit breaker: HALF_OPEN → CLOSED")
            
            self.failure_count = 0
            return result
        
        except Exception as e:
            self.failure_count += 1
            self.last_failure_time = datetime.now()
            
            if self.failure_count >= self.failure_threshold:
                self.state = CircuitState.OPEN
                logger.error(f"Circuit breaker: OPEN (failures: {self.failure_count})")
            
            raise e

# 전역 인스턴스
_neo4j_circuit = CircuitBreaker(failure_threshold=5, timeout=60)
_llm_circuit = CircuitBreaker(failure_threshold=3, timeout=30)
```
