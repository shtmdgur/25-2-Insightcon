## 시계열이란 무엇인가?

### 기본 개념

**시계열(Time Series)**은 시간에 따라 순서대로 관측되는 데이터의 열입니다.
보통 다음과 같이 나타냅니다:

[
X = {x_t \mid t = 1,2,\dots,T}
]

* ( t ): 시간 인덱스 (예: 거래일, 분, 초)
* ( x_t ): 해당 시점의 관측값 (예: 종가, 거래량, 환율)

### 예시 (삼성전자 일별 종가)

| 날짜         | 가격(원)  |
| ---------- | ------ |
| 2024-01-02 | 70,000 |
| 2024-01-03 | 71,200 |
| 2024-01-04 | 69,800 |
| 2024-01-05 | 70,500 |

이 전체 열이 하나의 시계열입니다.

### 시계열에서 자주 보는 구성 요소

* **Trend(추세)**: 장기적인 상승/하락 방향
* **Seasonality(계절성)**: 주기적으로 반복되는 패턴
* **Noise(잡음)**: 설명되지 않는 랜덤한 변동
* **Volatility(변동성)**: 변동폭의 크기

## 금융 시계열의 특징

금융 시계열(주가, 수익률, 거래량 등)은 일반적인 시계열보다 더 까다로운 특성이 있습니다.

### 1. 비정상성(Non-stationarity)

* 평균, 분산, 상관 구조가 시간이 지나면서 변하는 경우가 많음
* 예: 호황기/불황기, 정책 변화, 이벤트 발생 시 구조 자체가 바뀜

### 2. 변동성 군집(Volatility Clustering)

> “조용한 날은 계속 조용하고, 요란한 날은 계속 요란하다”

* 큰 폭 변동이 나온 시기에는 그다음 며칠도 큰 변동이 이어지는 경향
* GARCH류 모델이 이런 현상을 모형화

### 3. Fat Tails (두터운 꼬리)

* 극단적인 수익률(급등/급락)의 발생 확률이 정규분포보다 크다
* 리스크 관리에 중요한 요소

### 4. 가격 vs 수익률

* **가격(Price)**: ( P_t )
* **수익률(Return)**:

  * 단순 수익률: ( r_t = \frac{P_t - P_{t-1}}{P_{t-1}} )
  * 로그 수익률: ( r_t = \ln(P_t) - \ln(P_{t-1}) )

온톨로지/LLM 레벨에서 직접 쓰기에는 **가격 자체보다 “상태(State)”로 변환한 표현**이 더 유용합니다.

## 시계열의 심볼릭 표현: SAX & SAX-DM

### 1. 왜 심볼릭 표현이 필요한가?

LLM은 숫자(70,000 / 71,200 / 69,800…)의 미세한 변화를 정량적으로 잘 다루지 못합니다.
대신 이런 표현이 훨씬 이해하기 쉽습니다:

* “완만한 상승 추세(Soft Uptrend)”
* “강한 하락과 높은 변동성(Strong Down, High Volatility)”
* “노이즈 구간(Sideways / Noise)”

**SAX/SAX-DM**은 **시계열 → 심볼(Symbol) 시퀀스**로 바꿔주는 역할을 합니다.

---

### 2. SAX (Symbolic Aggregate approXimation)

**개념 요약**

1. 시계열 구간별 평균을 구하고 (PAA)
2. 평균값을 구간별로 나눠 알파벳 심볼로 매핑

#### (1) PAA (Piecewise Aggregate Approximation)

예: 6개의 시계열을 3구간으로 나누기

원본:
[
[70,000, 71,200, 69,800, 70,500, 72,000, 71,500]
]

3구간 평균:

* 구간 1: (70,000 + 71,200) / 2
* 구간 2: (69,800 + 70,500) / 2
* 구간 3: (72,000 + 71,500) / 2

#### (2) 평균값 → 심볼 매핑

정규화 후 평균 위치에 따라:

* 매우 낮음 → `A`
* 낮음 → `B`
* 보통 → `C`
* 높음 → `D`
* 매우 높음 → `E`

예: `["B", "C", "D"]` 같은 문자열로 표현.

---

### 3. SAX-DM (Double Mean) – 시계열의 “강도까지” 표현

SAX는 **값의 상대적 위치**는 잘 표현하지만,
**상승/하락의 강도, 방향성**을 명시적으로 담기엔 부족합니다.

그래서 **SAX-DM (Double Mean)**은 “평균을 두 번 나눠서” 추세 강도를 표현합니다.

#### SAX-DM 핵심 아이디어

1. 시계열을 정규화:
   [
   z_t = \frac{x_t - \mu}{\sigma}
   ]
2. 전체 평균 ( \mu ) 기준으로 양수/음수 영역을 나눔
3. 음수 영역 평균(하단 평균), 양수 영역 평균(상단 평균)을 다시 계산
4. 각 시점의 값이 어디에 속하는지에 따라 심볼을 부여:

예시 심볼 체계:

| 구간                                   | 심볼   | 의미                  |
| ------------------------------------ | ---- | ------------------- |
| ( z_t \le \mu_{\text{lower}} )       | `D2` | 강한 하락 (Down Strong) |
| ( \mu_{\text{lower}} < z_t \le \mu ) | `D1` | 약한 하락 (Down Mild)   |
| ( \mu < z_t \le \mu_{\text{upper}} ) | `U1` | 약한 상승 (Up Mild)     |
| ( z_t > \mu_{\text{upper}} )         | `U2` | 강한 상승 (Up Strong)   |

이렇게 하면 **하나의 시점/구간을 “강도 + 방향”을 가진 상태로 표현**할 수 있습니다.

#### 간단한 파이썬 예시 (개념용)

```python
import numpy as np

def sax_dm(values):
    values = np.array(values, dtype=float)
    z = (values - values.mean()) / values.std()

    mu = z.mean()
    lower = z[z <= mu]
    upper = z[z > mu]

    mu_lower = lower.mean() if len(lower) > 0 else mu
    mu_upper = upper.mean() if len(upper) > 0 else mu

    symbols = []
    for v in z:
        if v <= mu_lower:
            symbols.append("D2")  # 강한 하락
        elif v <= mu:
            symbols.append("D1")  # 약한 하락
        elif v <= mu_upper:
            symbols.append("U1")  # 약한 상승
        else:
            symbols.append("U2")  # 강한 상승
    return symbols
```

## TimeSeriesState 개념과 구조

### 1. TimeSeriesState란?

> **특정 날짜, 특정 자산의 “시장 상태(State)”를 요약한 추상 객체**

수치 기반 시계열을:

* 상승/하락 방향 (trend)
* 강도 (SAX-DM symbol)
* 변동성 (volatility level)
* 핵심 지표 상태 (RSI overbought/oversold 등)

로 요약한 결과를 **하나의 인스턴스(ABox)**로 표현합니다.

### 2. 수학적 정의

하나의 자산 ( A )에 대해:

* 가격 시계열: ( P_t )
* 변환 함수 ( f )를 정의:

[
\text{state}*t = f(P*{t-k},\dots,P_t,\text{기타지표})
]

그러면:

[
\text{TimeSeriesState}(A, t) =
{ \text{date}=t,\ \text{sax_symbol},\ \text{trend},\ \text{volatility},\ \text{return},\ \dots }
]

### 3. TimeSeriesState 속성 설계

**필수 속성**

* `date`: 해당 상태가 대표하는 날짜 (`xsd:date`)
* `sax_symbol`: SAX-DM 심볼 (`"U2"`, `"D1"` 등)
* `trend`: `"Uptrend"`, `"Downtrend"`, `"Sideways"`, `"Reversal"`
* `volatility`: `"Low"`, `"Medium"`, `"High"` 등 변동성 레벨
* `price`: 해당 일자의 종가
* `daily_return`: 일간 수익률
* `zscore`: 가격의 표준화 값(평균 대비 얼마나 벗어났는지)

**선택 속성**

* `indicator_state`: `"RSI_Overbought"`, `"RSI_Oversold"`, `"RSI_Neutral"` 등
* `volume_state`: 거래량 고/저 구간
* `window_size`: 상태 산출에 사용한 윈도우 길이

### 4. 예시 (삼성전자 2024-08-15 상태)

```json
{
  "state_id": "005930_2024-08-15",
  "ticker": "005930",
  "date": "2024-08-15",
  "price": 70100,
  "sax_symbol": "U1",
  "trend": "Uptrend",
  "volatility": "Medium",
  "daily_return": 0.015,
  "zscore": 1.21,
  "indicator_state": "RSI_Overbought"
}
```

Neo4j 노드:

```cypher
(:TimeSeriesState {
  state_id: "005930_2024-08-15",
  date: date("2024-08-15"),
  price: 70100,
  sax_symbol: "U1",
  trend: "Uptrend",
  volatility: "Medium",
  daily_return: 0.015,
  zscore: 1.21,
  indicator_state: "RSI_Overbought"
})
```

그리고:

```cypher
(:Company {ticker:"005930"})-[:HAS_STATE]->(:TimeSeriesState {...})
```

## 시계열 → TimeSeriesState 변환 파이프라인

### 전체 흐름

1. **가격 데이터 수집**

   * 예: yfinance, 증권사 API, 자체 DB
2. **전처리**

   * 결측치 처리, 로그변환, 리턴 계산
3. **SAX-DM 변환**

   * 정규화 → Double Mean 기준 → `U1/U2/D1/D2` 심볼 생성
4. **추가 지표 계산**

   * 변동성, RSI, Z-score 등
5. **TimeSeriesState 생성 & Neo4j 적재**

   * 속성 채우고, `HAS_STATE` 관계로 Company에 연결

---

### 예시 파이프라인 (개념 코드)

```python
import pandas as pd
import numpy as np
from neo4j import GraphDatabase

# 1. 데이터 로드 (예: 삼성전자 2년치 종가)
df = pd.read_csv("samsung_2y.csv")  # date, close

# 2. 수익률 / z-score / 변동성 계산
df["return"] = df["close"].pct_change()
df["zscore"] = (df["close"] - df["close"].rolling(60).mean()) / df["close"].rolling(60).std()

# 3. SAX-DM 심볼 부여
def sax_dm(values):
    values = np.array(values, dtype=float)
    z = (values - values.mean()) / values.std()
    mu = z.mean()
    lower = z[z <= mu]
    upper = z[z > mu]
    mu_lower = lower.mean() if len(lower) > 0 else mu
    mu_upper = upper.mean() if len(upper) > 0 else mu
    symbols = []
    for v in z:
        if v <= mu_lower:
            symbols.append("D2")
        elif v <= mu:
            symbols.append("D1")
        elif v <= mu_upper:
            symbols.append("U1")
        else:
            symbols.append("U2")
    return symbols

df["sax_symbol"] = sax_dm(df["close"].dropna())

# 4. Trend / Volatility 레이블링 (간단 버전)
def label_trend(symbol):
    if symbol in ["U1", "U2"]:
        return "Uptrend"
    elif symbol in ["D1", "D2"]:
        return "Downtrend"
    else:
        return "Sideways"

def label_volatility(ret_series):
    sigma = ret_series.rolling(20).std()
    # 분위수 기반 구간화 등
    # 여기서는 단순 예시
    vol = []
    for v in sigma:
        if v < 0.01:
            vol.append("Low")
        elif v < 0.03:
            vol.append("Medium")
        else:
            vol.append("High")
    return vol

df["trend"] = df["sax_symbol"].apply(label_trend)
df["volatility"] = label_volatility(df["return"])

# 5. Neo4j에 TimeSeriesState 적재 (개념)
driver = GraphDatabase.driver("neo4j_uri", auth=("user","pwd"))

with driver.session() as session:
    for _, row in df.iterrows():
        if pd.isna(row["return"]):
            continue
        state_id = f"005930_{row['date']}"
        session.run("""
            MERGE (s:TimeSeriesState {state_id: $state_id})
            SET s.date = date($date),
                s.price = $price,
                s.sax_symbol = $sax_symbol,
                s.trend = $trend,
                s.volatility = $volatility,
                s.daily_return = $ret,
                s.zscore = $zscore
            WITH s
            MERGE (c:Company {ticker: "005930"})
            MERGE (c)-[:HAS_STATE]->(s)
        """, {
            "state_id": state_id,
            "date": row["date"],
            "price": float(row["close"]),
            "sax_symbol": row["sax_symbol"],
            "trend": row["trend"],
            "volatility": row["volatility"],
            "ret": float(row["return"]),
            "zscore": float(row["zscore"]) if not pd.isna(row["zscore"]) else 0.0
        })
```

## 온톨로지 및 Neo4j 통합

### 1. TBox에 TimeSeriesState 추가

Protege에서:

```text
Class: TimeSeriesState
  DatatypeProperty: hasDate          -> xsd:date
  DatatypeProperty: hasSAXSymbol     -> xsd:string
  DatatypeProperty: hasTrend         -> xsd:string
  DatatypeProperty: hasVolatility    -> xsd:string
  DatatypeProperty: hasPrice         -> xsd:float
  DatatypeProperty: hasReturn        -> xsd:float
  DatatypeProperty: hasZScore        -> xsd:float
  DatatypeProperty: hasIndicatorState -> xsd:string

ObjectProperty: HAS_STATE
  Domain: Company
  Range: TimeSeriesState
```

Events와의 관계도 정의 가능:

```text
ObjectProperty: AFFECTS_STATE
  Domain: Event
  Range: TimeSeriesState
```

### 2. ABox 예시 (RDF 스타일)

```turtle
:Samsung a :Company ;
    :hasTicker "005930" .

:State_005930_2024_08_15 a :TimeSeriesState ;
    :hasDate "2024-08-15"^^xsd:date ;
    :hasSAXSymbol "U1" ;
    :hasTrend "Uptrend" ;
    :hasVolatility "Medium" ;
    :hasPrice 70100 ;
    :hasReturn 0.015 ;
    :hasZScore 1.21 .

:Samsung :HAS_STATE :State_005930_2024_08_15 .

:HBMContract2025 a :Event ;
    :positiveImpacts :Samsung ;
    :AFFECTS_STATE :State_005930_2024_08_15 .
```

※ n10s로 OWL/Turtle을 Neo4j로 가져오면 이 구조 그대로 그래프에 반영됨.

## 멀티에이전트·투자 의사결정에서의 활용

### 1. Bull Agent (강세론자)

* 최근 TimeSeriesState 조회:

  * `trend = Uptrend`
  * `sax_symbol in [U1, U2]`
  * `volatility = Medium 이하`
* 최근 Event:

  * `POSITIVE_IMPACTS` 있는 Event 존재
* → “강한 모멘텀 + 긍정적 이벤트 → 매수 주장”

### 2. Bear Agent (약세론자)

* 최근 TimeSeriesState:

  * `volatility = High`
  * `indicator_state = RSI_Overbought`
  * `zscore` 과열 구간
* Event:

  * 긍정적이지만 이미 가격에 반영됐다고 주장
* → “단기 과열 → 조정 가능성 주장”

### 3. Trader Agent (판사)

* 두 에이전트가 참조한 TimeSeriesState와 Event를 동시에 보고
* “이벤트 이후의 상태 변화”까지 고려해

  * 포지션 크기
  * 진입/청산 시점
  * 리스크 한도
    를 결정

## 요약 및 다음 문서

### 요약

1. **시계열(Time Series)**은 시간에 따라 관측된 데이터 열이며, 금융 시계열은 비정상성·변동성 군집 등 특수한 특성을 가진다.
2. **SAX/SAX-DM**은 시계열을 **심볼(상승/하락·강도)**로 변환해 LLM과 온톨로지의 “언어”로 옮기는 다리 역할을 한다.
3. **TimeSeriesState**는 특정 날짜의 자산 상태를

   * `date`, `sax_symbol`, `trend`, `volatility`, `price`, `return` 등 속성으로 표현하는 ABox 인스턴스이다.
4. 시계열 데이터는 Python에서 계산하고, 결과를 **TimeSeriesState 노드**로 Neo4j에 적재한 뒤,

   * `Company -[:HAS_STATE]-> TimeSeriesState`
   * `Event -[:AFFECTS_STATE]-> TimeSeriesState`
     형태로 온톨로지/지식그래프에 통합한다.
5. 멀티에이전트 시스템(Bull/Bear/Trader)은 이 상태 정보를 기반으로 **설명 가능한 투자 의사결정**을 수행한다.
